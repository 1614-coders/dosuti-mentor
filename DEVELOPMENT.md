## Лёгкий статус подготовки

`course.py preparation-status --course COURSE --lesson ID` читает текущую попытку
без блокировки занятой QA-операции. `preparation-step` с `--step frames_review`,
`code_review` или `ready` и `--time T --window W` отмечает фактический этап чата.
Ready — отчёт ассистента для окна; перед преподаванием проверяй context.

## Отмена и сводка

Прочитай preparation-status и используй полученный attempt_id:

```sh
python course.py preparation-cancel --course COURSE --lesson ID --attempt ATTEMPT_ID
python course.py preparation-summary --course COURSE --lesson ID
```

Отмена не ждёт эксклюзивную QA-операцию. Запрос не равен завершению: перечитай
статус до interrupted/failed. Старый ID не отменит новую попытку. Нет сигналов
произвольным PID или завершения по имени программы. На POSIX дочерние команды
имеют свою process group; на Windows используется дерево живого дочернего PID.
Длительная проверка/публикация в Python замечает отмену между этапами.
Сводка качества проверяет источники и может хешировать видео: вызывай после
операции, а не каждые 30 секунд. Время worker вложено в родительское, общие
модели/runtime не входят в место лекции. Прежние курсы не требуют миграции.
