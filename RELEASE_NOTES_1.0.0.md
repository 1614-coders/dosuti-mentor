# DoSuti Mentor 1.0.0 — примечания к релизному пакету

DoSuti Mentor 1.0.0 — релизный пакет помощника для Codex.
Официальный канал установки — стабильная ветка `main`.
Фактическую установленную версию проверяйте по manifest установленного пакета
и источнику установки. Номер в этом документе не подтверждает публикацию
или установку пакета на вашем компьютере.

## Что делает наставник

DoSuti Mentor — помощник в Codex для обучения шаг за шагом. Он задаёт восемь
вопросов знакомства по одному, позволяет их пропустить, обсуждает цель и план,
помогает с диагностикой, объясняет темы, предлагает практику и разбирает ответы.
Сохраняет локальные курсы, профили и прогресс для продолжения в новом чате.
Пользователь выбирает курс; поиск вакансий требует согласия.

В пакет входят подготовка материалов и работа с локальными источниками.
Для macOS/Linux предусмотрены текст, код, PDF и видео; видео может потребовать
отдельной загрузки модели и заметного свободного места. Учебный ИИ не гарантирует
правильность каждого ответа или качество распознавания.
Новых учебных возможностей и миграций формата в этом пакете нет.

## Платформы

Статус поддержки macOS/Linux определяется результатами релизной приёмки.
Windows — **experimental / limited support**, не Windows Stable.
В базовом CI каждый Windows-профиль имеет 7 failures, 41 errors и 85 skipped;
эти результаты не скрыты и suite остаётся включённым.
[Матрица платформ](SUPPORTED_PLATFORMS.md) · [Известные проблемы Windows](WINDOWS_KNOWN_ISSUES.md).

## Установка

В Codex попросите установить DoSuti Mentor из `1614-coders/dosuti-mentor`, ветка
`main`. Токен владельца репозитория и доступ к его аккаунту не нужны. Используйте
Git marketplace, а не локальную develop-копию. [Пошаговая установка](README.md#как-установить).
После установки проверьте источник и версию обоих manifests установленного пакета,
доступность setup-dosuti и start-learning, затем проверку локальных компонентов.
При успехе откройте новый чат и напишите `$start-learning`.

## Обновление и данные

Перед обновлением остановите обработку и записи. Скопируйте весь DATA_ROOT,
внешние курсы и файлы их подключений. Не копируйте работающую SQLite-базу отдельно
от её окружения. [Ручная копия](plugins/dosuti-mentor/references/installation.md#ручная-копия-учебных-данных-при-остановленных-процессах).

Уже настроенный marketplace обновляется штатной командой upgrade с ref main.
Смена чужого/local источника требует согласованного перехода; обновление каталога
не доказывает обновления установленной копии. Не удаляйте профиль или курсы ради
переустановки. При неудаче остановитесь, сохраните диагностику и прежний runtime.
[Порядок обновления](plugins/dosuti-mentor/references/installation.md#обновление-установленного-плагина).

По умолчанию данные находятся в `~/Library/Application Support/DoSutiMentor` на macOS,
в `$XDG_DATA_HOME/DoSutiMentor` (обычно `~/.local/share/DoSutiMentor`) на Linux,
в `%LOCALAPPDATA%\DoSutiMentor` на Windows. Явно выбранный DATA_ROOT и внешние курсы
сохраняются. Курсы — в courses, общие предпочтения — в learner-preferences;
подробнее [схема хранения](STORAGE.md).

## Безопасность зависимостей

Минимум Pillow повышен с диапазона 11–12 до **13.0.0**, верхняя граница `<14`.
12.3.0 нельзя считать безопасной установленной зависимостью: опубликовано
[исправление JPEG decoder overflow](https://github.com/python-pillow/Pillow/security/advisories/GHSA-8g5g-8vmr-9782).
Обновление среды использует прежний проверяемый staging-механизм.
Не отключайте проверки или sandbox ради успешной установки.

## Проверки и известные ограничения

На этапе подготовки пакета (9 ноября 2026 года) живой сценарий Codex install →
новый чат → обучение → перезапуск имел статус **NOT VERIFIED**.
Актуальное подтверждение проверяйте по протоколу
[пользовательской приёмки](INSTALLATION_ACCEPTANCE.md), Linux release CI
и отдельным нативным Windows-прогонам. Исторический результат подготовки
не заменяет проверку фактически установленного пакета.
Исправление H01 и черновой Job Publication backend не включены в пакет 1.0.0.
