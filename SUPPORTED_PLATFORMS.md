# Платформы DoSuti Mentor 1.0.0

Это политика релизного кандидата, а не объявление опубликованного релиза.

| Платформа | Статус кандидата | Условия |
|---|---|---|
| macOS, CPython 3.11/3.12 | Кандидат на стабильную поддержку | Полный локальный прогон и установочная приёмка; живой диалог отдельно |
| Linux, CPython 3.11/3.12 | Кандидат на стабильную поддержку | Базовый Linux CI зелёный; patch 1.0.0 требует нового Linux CI |
| Windows x64, local NTFS, CPython 3.11/3.12 | Experimental / limited support | PS7/PS5.1 имеют известные failures/errors; полнота pipeline не подтверждена |
| Windows ARM/32-bit, сетевые диски, иные файловые системы | Не заявлены | Без небезопасного fallback |

Локальный runtime проверен на macOS arm64. macOS x86_64, Linux aarch64 и
другие сочетания архитектуры/версии Python отдельно не подтверждены этим прогоном.

Для стабильного статуса macOS/Linux нужны результаты именно финального patch,
независимый аудит и сценарии из [приёмки установки](INSTALLATION_ACCEPTANCE.md).
Факт прохождения Python-теста не подтверждает весь живой диалог Codex.
Точные результаты разработки и остающиеся gates находятся в [чек-листе](RELEASE_CHECKLIST.md).

## Поддерживаемый сценарий и ограничения

Плагин помогает согласовать цель, пройти знакомство/диагностику, составить Roadmap,
обсуждать тему, выполнять практику и продолжать выбранный локальный курс.
Материалы, ответы и профили хранятся локально. Модель может ошибаться: ответы
проверяются по источникам и фактическим попыткам, а не по обещанию точности ИИ.

На macOS/Linux пакет содержит обработчики локальных текстов, кода, PDF и видео.
Видео требует FFmpeg и отдельной загрузки ASR-модели; качество распознавания,
OCR, сеть и доступ к внешнему сайту не гарантируются установкой.
Поиск вакансий выполняется только после согласия. Список курсов не переключает
курс автоматически; настройка плагина не начинает обучение.

На Windows подтверждены отдельные native компоненты, а не весь импорт/подготовка:
[ограничения и результаты](WINDOWS_KNOWN_ISSUES.md). Сначала используйте изолированный
QA-курс и копию учебных данных. При отказе не удаляйте staging, не обходите DACL,
reparse/no-follow или fail-closed проверки. Исходные файлы не следует заменять
ссылками/junction. Обнаружение повреждения — повод остановить зависимую операцию.

## Временные пути macOS

Полный локальный набор проверен с физическим тестовым TMPDIR внутри `/private/var`.
При исходном системном алиасе `/var/...` старые processing fixtures получают отказ
no-follow; это воспроизводится и на чистой базе. Продуктовую защиту ради теста
не ослабляли. Обработка должна использовать проверенный управляемый DATA_ROOT;
при ошибке пути остановите операцию и сохраните диагностику, не исправляйте
пути прогресса вручную. Не обещаем поддержку любого symlink-пути.

## Сохранность данных

Обновление версии не меняет форматы курсов и прогресса. Это не заменяет ручную
копию при остановленных процессах: сохраните весь DATA_ROOT и внешние курсы.
Автоматического Backup/Restore нет. [Где лежат данные](STORAGE.md).
