# Где лежат данные и как их убрать

Новый курс по умолчанию создаётся в управляемом доме данных, в `courses/default`,
только после явного start-learning. Существующие подключения и внешние курсы
сохраняются. В доме также находятся runtime, кеши и временные файлы; папка `models/` появится только при
первой загрузке локальной модели:

```text
DATA_ROOT/
  courses/       стандартный курс, материалы и профили после первого начала обучения
  runtime/       приватный Python и venv, если они понадобились
  models/        локальные модели распознавания
  cache/         кеши pip, загрузок и библиотек
  temp/          рабочие файлы активных процессов
  .dosuti-home.json
  .dosuti-mentor.json   существующий формат connections для стандартного курса
```

Стандартный курс и его подключение создаются только при начале обучения.
Новая папка проекта сама по себе не изолирует стандартный профиль. Установка не создаёт ни курс, ни модели, ни отчёты заранее.

Уроки, прикреплённые материалы и учебный прогресс сохраняются в папке курса.
Исходные файлы пользователя и системный Python не переносятся в эти каталоги и
не удаляются ими.

## Временные файлы и кеш

Обработчик получает собственные `TEMP`, `TMP`, `PIP_CACHE_DIR`, `HF_HOME` и
`XDG_CACHE_HOME` внутри DATA_ROOT. При обычном завершении временная папка задачи
удаляется. После аварийной остановки она может остаться для безопасного разбора.

Проверка Python на Windows использует отдельный `temp/python-probe-UUID`.
После завершения, ошибки или таймаута родитель останавливает дерево проверки,
дожидается остановки и удаляет только свой каталог. Если остановку подтвердить
не удалось или обнаружена ссылка/junction, каталог сохраняется с явной ошибкой.
Принудительное завершение самого PowerShell может оставить эту папку и требует
проверки процессов перед ручной очисткой. Старые probe-папки из системного `%TEMP%`
автоматически не удаляются: их принадлежность текущая установка не доказывает.

После подготовки лекции старые файлы кеша можно очистить командой:

```text
PYTHON PLUGIN_ROOT/scripts/managed_storage.py --home DATA_ROOT --apply --cache-mib 1024
```

Она удаляет только проверенные старые кеш-файлы сверх указанного бюджета. Модели,
runtime, уроки, ответы и отчёты не затрагиваются. При активной обработке очистка
откладывается.

## Восстановление runtime

При восстановлении runtime новая среда проверяется до переключения и повторно
по конечному пути. Предыдущая копия сохраняется в `runtime/venv-previous-*`
или `runtime/python-previous-*`; автоматически она не запускается и не удаляется.
После неудачного переключения также может остаться `venv-failed-*` или каталог
кандидата. При аварийном завершении процесса между переименованиями потребуется
проверить эти папки перед ручным восстановлением. Не удаляй резервные копии до
проверки новой установки; это дополнительные файлы в DATA_ROOT, не учебный прогресс.

## Полное удаление

Сначала заверши обработку и скопируй нужные материалы из курса. Затем закрой Codex
и удали выбранные папки курса и DATA_ROOT через Проводник. Если Windows сообщает,
что файл занят, закрой процесс, который его использует, и повтори удаление.

Удаление DATA_ROOT не удаляет плагин и чаты Codex. Их удаляют средствами самого
Codex. Системный Python, внешние модели и файлы вне выбранных папок остаются на
компьютере.
