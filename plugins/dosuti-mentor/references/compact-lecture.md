# Компактная лекция0.4.39

Цель — повторять занятие без оригинального видео/извлечённого аудио, сохранив
расшифровку с таймкодами, все опубликованные кадры, экранные заметки, правила,
снимки кода/этапы, домашку и прогресс курса. Короткий конспект не заменяет их.
Новый skill `$compact-lecture` проводит через подготовку и план. Автоочистки нет.

## Команды и договорённости

```sh
python -B plugins/dosuti-mentor/scripts/course.py compact draft --course COURSE --lesson LESSON
python -B plugins/dosuti-mentor/scripts/course.py compact plan --course COURSE --lesson LESSON --memory-file MEMORY.json
python -B plugins/dosuti-mentor/scripts/course.py compact apply --course COURSE --lesson LESSON --plan-file PLAN.json
python -B plugins/dosuti-mentor/scripts/course.py compact status --course COURSE --lesson LESSON
python -B plugins/dosuti-mentor/scripts/course.py compact reopen --course COURSE --lesson LESSON
```

Сохранить JSON draft вне папки конкретной лекции. Его необходимо содержательно
дополнить; шаблон не проходит проверку. Plan выводит объект {read_only,plan,...}:
в PLAN.json сохранить только вложенный plan. MEMORY/PLAN вне lesson: добавление
их внутрь меняет source_revision. Не перенаправлять stdout в compact.json: это
внутренняя квитанция, её пишет только apply.

Перед apply показать пользователю перечень удаляемого, объём и ограничения
восстановления, получить явное разрешение удалить именно эти медиа. Просьба
реализовать функцию или посмотреть объём не разрешает удаление реального курса.
При уже полученном разрешении на конкретный план повторного вопроса не нужно.
В QA использовать только копии/отдельные курсы. Код не отправляет материалы в сеть.

## Учебная память

Схема lecture_memory_v2 содержит review_scope и source_sha256, source_revision, duration, review,
topics, limitations. Draft сам закрепляет SHA источника и revision полного набора
сохраняемых файлов; после изменения кода/заметок/метаданных нужен новый draft/сверка.
Исходник должен быть доступен для первого плана: его длительность измеряется
probe_media. Всё занятие должно быть покрыто подготовленными пакетами. Разница
до0.1секунды на конечной границе допускается из-за медиатаймлайна.

review: speech/screen/code/homework со значением reviewed или not_present и notes
с описанием проверки. Присутствующий материал нельзя назвать отсутствующим;
сам draft имеет unreviewed и пустое объяснение. Это заявленная проверка ассистента
или человека, а не автоматическое доказательство полноты/точности.

review_scope фиксирует transcript (not_checked/read), frames
(not_checked/sampled/all_retained), checked_frame_ids, audio и speakers
(not_checked/sampled/full), code (not_checked/reviewed), homework_revision и
unresolved. Для sampled перечислить фактически просмотренные ID; all_retained
означает все сохранённые кадры, а не все кадры оригинального видео. reviewed
в review не означает прослушивание звука или независимую проверку. Эта область
самодекларируемая: программа проверяет структуру и ID, но не наблюдает сверку.
Прежняя v1 читается без изменения; её область проверки явно legacy_unknown.

Перед архивацией проверь конец/упоминания задания в ASR. Устную домашку сохранить
через [spoken-homework](spoken-homework.md), затем сформировать свежий draft памяти.
Реестр verbal-homework хранится в курсе вне запечатанной лекции. Его редакция
закрепляется в review_scope.homework_revision; изменение до apply требует новой
сверки. Изменение после архивации делает старую сверку задания неактуальной:
context предупреждает, а для проверки нужно брать текущий homework.

Каждая topic: title/start/end/teacher_explanation/teacher_examples/additions/
frame_ids/code_examples/uncertainties. Темы в совокупности покрывают занятие.
teacher_explanation хранит ход мысли преподавателя; teacher_examples — его
примеры/поправки. additions — дополнительные пояснения ассистента. Не выдавать
дополнение за реплику преподавателя. frame_ids берутся из context с его префиксом.
code_examples: language/code/at/frame_id/stage; нужен сохранённый кадр из этой темы.
Строки кода вручную сверяются, незавершённый ввод и подсказки IDE не дописываются
как готовый код. Если нечитаемо, записать uncertainties вместо выдуманного примера.

Для подготовки читать context смысловыми блоками, соседние кадры и этапы кода,
домашку и сохранённые дополнительные материалы. Проверять противоречия ASR,
UUID/скобки/времена/промежуточные состояния. Пакет сохраняет всю ASR и все кадры:
автоматическое покрытие не гарантирует, что выборка заметила краткое изменение.
Не менять прогресс и не объявлять ученика освоившим лекцию при архивации.

## Что удаляется и что остаётся

Apply удаляет только проверенные строки плана:
- Скачанный video-<32hex>.* внутри video/ текущей лекции, если receipt download.json
  совпадает с URL, SHA, именем и размером. Локальный оригинал пользователя, даже
  находящийся в папке курса, по этому правилу не удаляется.
- audio.wav активных подготовленных пакетов с подтверждённым audio_sha256.
- Совпадающие с опубликованной версией рабочие audio/frames завершённых jobs;
  используются прежние проверки cleanup-job. Заметки/расшифровки/checkpoint/lock
  рабочих jobs сохраняются. Уже очищенные jobs не повторяются.

Текущие/исторические снимки кода и прочие файлы сохраняются. Исторические пакеты
и неизвестные видео не удаляются: они могут занимать существенное место.
Внешние снимки кода вне папки занятия требуют сначала управляемую копию. Другие
внешние ссылки/сайты не становятся локальными автоматически: для постоянного
материала сохранить их текст/вложения через обычный приём материалов до архивации.
Модели распознавания остаются общими для пользователя и не входят в этот план.

## Продолжение, сбои и восстановление

compact.json хранит контрольную сумму плана, память и инвентарь оставляемых файлов.
Состояния pruning→compact; квитанция и receipts рабочих jobs записываются раньше
удаления. Повтор apply с тем же планом проверяет оставляемые и существующие
удаляемые файлы; отсутствующие из плана допустимы после прерывания. Изменённый
кадр/код/пакет останавливает дальнейшее удаление. Locks стабильны, для удаления
удерживаются lesson/download и найденные processing locks. Незавершённая/ошибочная
обработка, ссылки на удаляемое из другой лекции или материалов блокируют план.

Обычный context и video-sources unit читают сохранённые данные; lecture_memory
передаёт темы, пересекающие запрошенное окно, и отметку проверки.
Если тема выходит за окно, её нетаймированный пересказ, примеры, дополнения и
неопределённости скрываются: selection.overview_withheld=true. Код остаётся только
с at внутри окна и выбранным кадром. Полный пересказ доступен при запросе всей темы;
для узкого момента использовать ASR/кадры, а не приписывать ему поздний результат. Проверка всех закреплённых
сохраняемых файлов при чтении — консервативная, может добавить IO для большой лекции.
Новая запись оценок/курсоров остаётся в прежнем хранилище профиля. Если изменился
закреплённый материал, context отказывает, а не молча объясняет по старой памяти.
Курс можно перенести целиком; новые пути кадров разрешаются существующими anchors.

Новые кадры/повторное распознавание требуют оригинала. В компактном состоянии
prepare/frame/scan не скачивают его молча. Явный reopen сохраняет квитанцию со
статусом reopened, сам ничего не скачивает и не восстанавливает. После возврата
того же SHA источника используется prepare --rebuild: старый очищенный job уже
не является полной аудиопубликацией. Старые версии плагина не знают этого режима:
читать проверенный context они могут, управлять rebuild/cleanup следует версией0.4.38+.
Повторная архивация сохраняет предыдущую квитанцию в .compact-history.

Условие безопасности — обычные операции плагина и отсутствие враждебной подмены
файлов тем же пользователем во время удаления. Контрольные суммы не являются
подписью/аутентификацией. Произвольные внешние ссылки на файлы выявить нельзя.
Логический удалённый объём не обещает равное увеличение свободного места APFS.
Windows требует внешнего пилота; мак-тесты его не заменяют.
