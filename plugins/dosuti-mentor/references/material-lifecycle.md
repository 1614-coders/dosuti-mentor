# Материал → подготовка → урок

Перед подбором и особенно перед тяжёлой обработкой прочитай существующие материалы:

```sh
python "$PLUGIN/scripts/course.py" material-status --course /absolute/course
python "$PLUGIN/scripts/course.py" material-status --course /absolute/course --unit-id maps
python "$PLUGIN/scripts/course.py" material-status --course /absolute/course --lesson lesson-01 --time 0 --window 120
```

`$PLUGIN` — корень плагина, Python выбирай по commands.md. Просмотр строго read-only:
он проверяет уже сохранённые зависимости, не скачивает видео, не запускает ASR/OCR,
не создаёт профиль и не записывает отдельный журнал статусов. Без selector возвращает
кандидатов; совпадение названия не означает совпадение задачи, версии и источника.
Выбор подходящего unit делает ассистент по цели, criteria и sources.

| Статус | Значение и следующий шаг |
| --- | --- |
| materials_missing | Нет зарегистрированных unit/лекций. Найди подходящий материал. |
| selected | Источник зарегистрирован или показаны кандидаты для выбора. Это не подтверждает скачивание, обработку или готовность. |
| preparing | Существующий preparation-status показывает живую попытку. Наблюдай её, не запускай дубликат. |
| ready | Unit имеет актуальные проверенные зависимости и не содержит явных uncertainties; для лекции выбранный диапазон покрыт и сверка ready относится к нему. Открой learn-unit/context перед объяснением. |
| limited | Есть неопределённости, неполное покрытие, несверенные файлы или остановленная подготовка. Обозначь ограничение и работай только с подтверждённым материалом. |
| stale | Изменились или недоступны закреплённые зависимости/результат сверки. Сначала пересмотри источники; не пересохраняй unit автоматически для снятия stale. |

`material_status` в результате unit — та же проекция. `preparation_status` остаётся
единственным владельцем статуса процесса, отмены и фактической сверки лекции.
Завершение ASR не означает ready. Любая готовность — сохранённая аннотация ассистента,
а не автоматическое доказательство истинности или понимания ученика.

При `reuse_preparation=true` не повторяй ASR/OCR для тех же зависимостей: для unit
открой learn-unit, для лекции context и сохранённые OCR review/заметки. У лекции
reuse означает целостное покрытие, даже если ещё нужна ручная сверка (`limited`).
Проверь warnings и соответствие источника задаче. Для другого диапазона запроси
статус заново; неполные gaps готовь отдельно. Перестройка оправдана изменённым
источником/параметрами распознавания, реальной ошибкой или явной просьбой.
Отмена оставляет готовые артефакты; проверяй их актуальность и покрытие перед повтором.

Хеши и источники остаются в существующих unit/lesson/dependencies; тяжёлые пакеты,
медиа, OCR и текстовые снимки остаются в курсе. В profile сохраняются реальные
ответы/попытки и продолжение со ссылками, а не копии материалов. Смена current-кода,
видео, домашки или prerequisite учитывается штатными проверками source evidence;
исторический pinned-снимок сохраняет свою явную версию.

Перед обработкой назови пользователю материал и диапазон: сейчас подготовка,
затем урок. После неё сообщи готовый диапазон и ограничение. Если обучение уже
запрошено, начни первый блок; готовые файлы не записывай как прохождение ученика.
