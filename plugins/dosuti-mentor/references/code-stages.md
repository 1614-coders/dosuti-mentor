# Этапы кода внутри лекции

Команда `code-stage --course COURSE --lesson LESSON` показывает сохранённые этапы.
`context` возвращает пересекающиеся с окном `code_stages`, включая исторические
снимки. Непривязанный teacher_code остаётся исходным материалом, а не версией экрана.

После просмотра оригинальных кадров и чтения исходника сохрани JSON через
`code-stage --course COURSE --lesson LESSON --stage-file stage.json`:

```json
{
  "id": "initial-condition",
  "title": "Первый вариант условия",
  "start": 370,
  "end": 371,
  "code_sha256": "<content_sha256 снимка из context/status>",
  "file": "src/recommendations1.py",
  "screen_file": "recommendations.py",
  "match": "partial",
  "notes": "Видимые ветви совпадают; ввод и конец файла не показаны.",
  "frames": [{"time": 370, "sha256": "<sha256 кадра из context>"}]
}
```

Диапазон полуоткрытый [start,end); кадры должны попадать внутрь. Не растягивай
один проверенный кадр на всю тему: между образцами код мог меняться. Для перехода
запроси соседние кадры/scan-screen. Каждый этап связывает один файл снимка с именем
на экране. Пути исходника проверяются по inventory. Снимок может быть историческим.

`matches` означает заявленное ассистентом совпадение проверенного содержимого,
`partial` — лишь части, `differs` — установленное расхождение, `unknown` — связь
пока не установлена. В notes укажи проверенные строки/ограничения и расхождения.
Не используй matches для скрытой части файла или по одному названию. Хеши проверяют
сохранность свидетельств, а не правильность анализа. Код не выполняется командой.

При stale не используй запись как подтверждение. Пересечение этапов одного
screen_file отключает usable_as_screen_match и требует уточнения: система не выбирает
победителя. Даже usable_as_screen_match не является автоматическим доказательством.
Исторический снимок подходит для исторического момента, а не обязательно для конца
урока. При partial/differs показывай видимый код с пояснением расхождения; не достраивай
отсутствующие строки как будто они были на экране.

ID нельзя перезаписать случайно. Для исправления сначала явно удали аннотацию
`code-stage --course COURSE --lesson LESSON --remove ID`, затем добавь исправленную.
Это удаляет только аннотацию; снимки и кадры сохраняются. Истории редакций самой
аннотации пока нет. Пути вычисляются заново, поэтому перенос курса поддерживается.

Ограничения: ручная сверка ассистентом, без автоматического OCR, определения момента
изменения, объединения файлов в запускаемый проект или истории между лекциями.
Чтение списка проверяет свидетельства всех этапов; много этапов на длинном видео
может замедлить запрос. Добавление другого пакета само по себе не инвалидирует этап,
но замена/утрата использованного кадра, снимка или видео делает его устаревшим.
