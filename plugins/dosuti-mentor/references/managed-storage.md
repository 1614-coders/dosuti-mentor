# Управляемый дом данных

Маркер `.dosuti-home.json` связывает runtime, models, кеши и несколько курсов одной
установки. Новый Windows bootstrap создаёт его в выбранном PilotRoot; существующий
неизвестный непустой каталог не принимается за наш. Старые курсы сами не мигрируют.

В управляемом доме `prepare` использует HOME/models/MODEL по умолчанию, а старый
курс без маркера — прежний COURSE/.runtime/models/MODEL. Явный --model-path важнее.
Команды course.py обнаруживают дом по предкам курса и ограничивают временные файлы
своим процессом. Общий Python и явные внешние модели остаются внешними зависимостями.

Для места на диске:

```text
PYTHON PLUGIN_ROOT/scripts/managed_storage.py --home HOME --usage
PYTHON PLUGIN_ROOT/scripts/managed_storage.py --home HOME
PYTHON PLUGIN_ROOT/scripts/managed_storage.py --home HOME --apply --cache-mib 1024
```

Первое — логический размер по папкам (без внешних ссылок), второе — план обслуживания,
третье — применение. Активные аренды и bootstrap блокируют очистку. Сервис удаляет
только старые кеш-файлы сверх бюджета и брошенные temp/job-ID с маркером аренды.
Неизвестные временные файлы, runtime, модели, уроки, прогресс и отчёты сохраняются.
Native OCR на macOS хранит исполняемый помощник в HOME/runtime/native-UID;
обычная очистка кешей не должна удалять части его проверяемой сборки.

Бюджет 1 ГиБ применяется после подготовки лекции/Windows bootstrap, когда нет
других обработчиков; это не жёсткая квота в процессе скачивания. При занятости
очистка откладывается. Не обещай очистку старых общих кешей или журналов ОС.
Для полного удаления QA остаётся pilot_cleanup с внешним Python и полным экспортом;
при единственном Python внутри дома используй Complete-WindowsPilot.ps1 из
распакованной папки снаружи: он создаёт временного внешнего помощника, сохраняет
план/отчёт, затем применяет существующий проверяемый cleanup. Загрузки без кеша
требуют -AllowDownload. Сначала план, затем явный Apply. См. WINDOWS-PILOT.md. Плагин/чаты удаляются в Codex.

В управляемом доме lecture-worker ждёт общий `.heavy.lock` до импорта обработчика
и загрузки модели; сообщения ожидания идут в stderr, таймаут 6 ч. Не обещай FIFO
или общий предел памяти для разных домов. Setup зависимостей использует тот же слот.
Старая неуправляемая лекция не создаёт дом/блокировку автоматически.
На Windows повреждённый приватный Python резервируется перед заменой; при обычной
ошибке откатывается. Резервная копия не входит в автоматический кеш и сохраняется.
