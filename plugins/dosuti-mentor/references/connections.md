# Подключение курса к чату и проекту — 0.4.10

Команды сохраняют выбор курса/профиля, а не технически отключают доступность
навыков Codex. Пользователь говорит обычной фразой, команды подбирает ассистент.
Используй текущую выбранную папку проекта; не ищи настройки в родителях/других
проектах. Одноразовый явный выбор пользователя можно использовать без записи;
постоянное подключение требует просьбы связать курс.

## Чтение

```sh
PYTHON PLUGIN_ROOT/scripts/connection.py --project PROJECT --chat CHAT_ID
```

Приоритет: запись чата, затем курс проекта. Отключённый чат блокирует возврат
к проекту. Недоступный курс чата также не заменяется проектом: уточни путь, не
инициализируй курс заново. Верхний course_path в .dosuti-mentor.json — только
выбор проекта; не читай его в обход resolver при работе конкретного чата.

CHAT_ID — стабильный slug из контекста/занятия; тот же ID можно использовать в
intent --session. Нативный ID Codex не обнаруживается автоматически. Без --chat
возвращается выбор проекта. needs_chat_id=true означает наличие записей отдельных
чатов: выясни ID, прежде чем считать проектный результат выбором текущего чата.
Не назначай один default для всех чатов. Если ID потерян, уточни подключение.

binding содержит абсолютные пути: относительные разрешаются от папки настроек.
Используй course_path/profile/profiles_dir/runtime/model_path из результата.
Старый файл с course_path читается как проектный, ревизия0; без profile берётся
default. Неизвестные поля сохраняются. Повреждённый/неизвестный формат не заменяй
автоматически: сохрани для восстановления.

## Изменение подключения

Прочитай актуальную revision. Примеры команд для ассистента:

```sh
PYTHON PLUGIN_ROOT/scripts/connection.py --project PROJECT --action connect --scope chat --chat CHAT_ID --course COURSE --profile USER --expected-revision REV
PYTHON PLUGIN_ROOT/scripts/connection.py --project PROJECT --action connect --scope project --course COURSE --profile USER --expected-revision REV
PYTHON PLUGIN_ROOT/scripts/connection.py --project PROJECT --action disconnect --scope chat --chat CHAT_ID --expected-revision REV
PYTHON PLUGIN_ROOT/scripts/connection.py --project PROJECT --action disconnect --scope project --expected-revision REV
```

Connect принимает --runtime, --model-path, --profiles-dir. Явные относительные
пути также считаются от --project. Connect заменяет всю выбранную запись: передай
дополнительные пути заново. Новые подключения хранят абсолютные пути; при переносе
курса переподключи его. Старые относительные записи сохраняются до замены.

.dosuti-mentor.json пишется атомарно под .dosuti-mentor.lock с CAS. При конфликте
перечитай статус. До200 записей чатов и900000 байт, без молчаливого удаления.
Disconnect не удаляет курс/цель/прогресс/чат. Отключение проекта сохраняет явные
подключения чатов. Возврат отключённого чата — явный connect; автоматического
снятия отключения нет. SQLite bind связывает чат с занятием внутри курса и не
заменяет этот выбор курса. При --scope project и --chat результат показывает
эффективный выбор указанного чата, который может отличаться от изменённого проекта.

Чтение/проверка не создают настроек. Connect требует существующий курс
поддерживаемого формата; init отдельно. Учебные оценки при подключении не создаются.

## Проверка среды

```sh
PYTHON PLUGIN_ROOT/scripts/connection.py --project PROJECT --chat CHAT_ID --action check
```

При доступном курсе read-only doctor проверяет текущий Python, пакеты, FFmpeg,
вспомогательные программы, место и явно указанный model_path. Без курса checked=false.
Нет скачивания модели, установки пакетов, обработки видео и сетевых обращений.
model=not_requested не означает готовность; structurally_ready не доказывает ASR.
Git/curl/ffprobe нужны отдельным сценариям, а не всему обучению.

interpreter — реально проверенный Python; configured_runtime — только сохранённая
папка. Для проверки другого runtime выбери его доверенный Python и повтори команду.
Путь из неизвестного файла настроек не является разрешением исполнять программу.
Веб-поиск и доступ/лимиты Codex из пакетов Python не выводятся: web_search=unknown;
ассистент проверяет реальные инструменты чата. При недоступности скажи об этом.

Приветствие не требует полной медиасреды. Intent достаточно Python3.11+, новая
обработка требует пакетов и модели; повторное чтение готовой лекции не требует
нового распознавания. Команды установки runtime — commands.md.

## Совместимость после переименования

Новые проекты используют .dosuti-mentor.json и ключ dosuti_mentor_connections.
Если нового файла нет, читается .lecture-tutor.json с прежним ключом; запись
сохраняет старое расположение и lock, чтобы прежние подключения не потерялись.
Чтение само по себе не мигрирует файлы. При наличии нового файла он приоритетен.
Курс, профиль, ревизии и выбор отдельных чатов сохраняются. Не создавай новый
пустой файл настроек для существующего подключения ради смены бренда.
