# Визуальные материалы — этап0.8.5

Используется прежнее хранение: кадры подготовленного видео/scan-screen и папка
ресурса PDF. Новый движок уроков, OCR и отдельная база изображений не создаются.

## Сначала кандидаты, затем просмотр

Читай visual_materials в source_contexts нужного unit. Видео-кандидаты — ссылки
на уже проверенные кадры внутри диапазона источника. Совпадающий SHA256 объединяет
повторные состояния; first_locator/locator/occurrence_count сохраняют сведения
о повторении. Завершающее состояние имеет приоритет. При избытке состояний
выбираются временные опоры; алгоритм не определяет смысл схемы или рукописи.
Остальные исходные кадры не удаляются и остаются доступными через context/scan-screen.

Сначала оцени текст/время/метаданные и обзорные листы, затем смотри лишь нужные
оригиналы кандидатов. Для постепенного рисунка выбирай итог и действительно
полезные промежуточные стадии после просмотра. Не называй каждый пиксельный сдвиг
этапом решения. Если важного состояния нет в подборке, используй прежний ограниченный
scan-screen или точный frame, не объявляй непроверенную картинку восстановленной.

## PDF: только выбранные страницы

Текстовое извлечение не менялось. По номерам страниц в выбранном отрывке/пометкам
неполноты запроси небольшой набор превью, не рендери весь документ автоматически:

```sh
PYTHON PLUGIN_ROOT/scripts/course.py resource --course COURSE --lesson LESSON --resource-id RESOURCE --action extract --visual-pages 1 2
```

Новый параметр необязателен; прежний extract работает как раньше. Изображения
сохраняются в подпапке visuals существующего ресурса и регистрируются тем же
update_lesson. Дорисовываются только отсутствующие страницы; единый бюджет
ограничивает накопленный кеш ресурса, а не каждый запрос заново. Проверенные результаты повторно используются без рендера.
Одинаковые растровые страницы делят один PNG, номера страниц сохраняются.
Смысловое распознавание картинки не выполняется. Рендер — ограниченное превью
целой страницы, не извлечение каждой отдельной формулы/иллюстрации и не OCR.
Оригинальный PDF остаётся доступным. Для повышения разрешения/детализации нужна
явная настройка в пределах бюджета и сверка оригинала; недостающие символы не угадывай.

## Явная связь с темой unit

В источнике kind=video или kind=resource карточки можно добавить visuals:

```json
{"visuals":[{"id":"page-1","caption":"Схема из выбранной страницы","notes":"Изображение просмотрено; связь с выбранным фрагментом и темой unit проверена"}]}
```

Это дополнение к обычному источнику с lesson/start/end или resource_id/строками,
не самостоятельная карточка. Видео использует точный scoped frame ID кандидата
или доступного кадра из того же диапазона. Нельзя подставить другую страницу,
кадр вне диапазона или произвольный путь. При сохранении фиксируются SHA256
изображения/оригинала; при чтении сверяются они и пригодность PNG/JPEG.
Проверка означает прослеживаемую ручную связь с unit, не независимую проверку
содержания. Плохо читаемое изображение можно показать с честной оговоркой, но
нельзя придумывать его расшифровку. Изменение visuals — обычное изменение версии
unit: старая история обучения сохраняется, оценки не создаются автоматически.

## Показ в уроке

Candidate.can_display=false: это только метаданные для выбора/просмотра.
Selected.can_display=true появляется после записи явной связи; запись содержит
markdown и link с абсолютным локальным путём. Вставляй markdown в подходящую часть
объяснения и называй страницу/время. Не показывай все candidates автоматически.
Если клиент не отображает локальное изображение, используй link и честно объясни
ограничение клиента. Для старого режима lecture остаются прежние проверки кадра,
времени и visual_notes; контекст unit не подменяет их.

meaning_verified=false всегда: ни хеш, ни картинка, ни ручная связь не отменяют
fact_assurance, оговорки ASR/PDF/HTML и систему проверки фактов.

## Бюджеты

DOSUTI_VISUAL_LIMITS — необязательный JSON окружения с частью полей:

```json
{"max_candidates":8,"max_display":3,"max_disk_bytes":16777216,"timeout_seconds":20,"max_pixels":4000000,"max_context_bytes":24576}
```

Это значения по умолчанию. Жёсткие максимумы:24 кандидата/страницы,12 выбранных
изображений,64MiB за операцию,45 секунд рендера,12 миллионов пикселей,
64KiB визуального блока контекста. max_context_bytes не меньше1024.
Остальные лимиты положительные целые, неизвестные поля отклоняются.

timeout_seconds ограничивает отдельный PDF worker; существующие видео-таймауты
и лимиты scan-screen сохранены. Это не ограничение полного времени ответа модели.
max_disk_bytes ограничивает кеш PDF-ресурса и выбранные ссылки, не всю историю курса.
Во время подготовки новых страниц временные копии могут потребовать ещё до
одного такого бюджета; после регистрации staging удаляется. Снижение бюджета ниже
уже сохранённого объёма вызывает явный отказ. Пиксельный лимит готового кеша закреплён;
другая настройка разрешения требует отдельного ресурса, без молчаливой замены изображений.
max_context_bytes относится только к visual_materials, не всему прежнему CLI-ответу.
Изображения не кодируются base64 и не отправляются все модели через CLI.

omitted_pages, omitted_count, selected_omitted_count и context_limited явно
отмечают ограничение. Часть omitted_count — точные повторения, их число отдельно
в duplicate_count. Исходники не уничтожаются ради бюджета. Токены изображений
и реальные затраты модели этой программой не измеряются.

Ошибки/таймаут/конфликт регистрации очищают только файлы текущей попытки через
существующий material_import. Зарегистрированные изображения не удаляются.
Повторные запросы используют общий кеш; новые страницы добавляются в пределах
его лимитов. Отдельная блокировка ресурса охватывает регистрацию и откат. После
жёсткого завершения процесса могут остаться непроверенные файлы: они не принимаются
за кеш автоматически и не удаляются вслепую. Полное
удаление управляемого курса использует прежний механизм. Перенос курса сохраняет
пути через существующие storage_paths.

Старые курсы/источники без visuals читаются без миграции. Старый плагин не знает
новые source-поля и якорь visuals.folder: для отката нужна совместимая резервная
копия; нельзя молча удалять данные из действующего курса.
