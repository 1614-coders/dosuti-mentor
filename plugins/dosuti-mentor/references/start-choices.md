# Выбор курса для проекта и чата

Сначала вызови learning_start без мутации. Действие определяется start_action,
не только enabled. Известный курс/настройки не разрешают выбрать его за ученика.

При choose_course задай дословно:

«Этот проект (чат) будет продолжением существующего курса или начнём новый?»

1. Продолжить существующий курс.
2. Создать новый курс.
3. Работать без привязки к курсу.

При уже однозначно сообщённом выборе сразу выполни его после чтения ревизии,
не показывай тот же вопрос снова. Пути, JSON и CLI пользователю не выводи.

```text
PRIVATE_PYTHON PLUGIN_ROOT/scripts/learning_start.py --project PROJECT --chat CHAT --home DATA_ROOT
PRIVATE_PYTHON PLUGIN_ROOT/scripts/learning_start.py --project PROJECT --chat CHAT --home DATA_ROOT --choice existing
PRIVATE_PYTHON PLUGIN_ROOT/scripts/learning_start.py --project PROJECT --chat CHAT --home DATA_ROOT --choice existing --course COURSE --expected-revision REVISION
PRIVATE_PYTHON PLUGIN_ROOT/scripts/learning_start.py --project PROJECT --chat CHAT --home DATA_ROOT --choice new --expected-revision REVISION
PRIVATE_PYTHON PLUGIN_ROOT/scripts/learning_start.py --project PROJECT --chat CHAT --home DATA_ROOT --choice none --expected-revision REVISION
```

Для чата без проекта опусти --project. --profile выбирает конкретного локального
ученика; не заменяй его чужим default. --expected-revision относится к connections
из последнего start, а не к оценкам/настройкам. При конфликте перечитай состояние;
не повторяй запись автоматически поверх нового выбора другого чата.

existing без пути возвращает select_course и список известных подключений этого
ученика (без сканирования всех курсов). Предложи выбрать курс по названию. Можно
использовать явно выбранную человеком внешнюю папку; это не разрешение искать
чужие профили. При нескольких несовместимых конфигурациях одного курса сначала
уточни выбранное подключение. Сохранённые runtime/model_path/profiles_dir не
подменяй. После успешного выбора спроси только если задача ещё неизвестна:

«Что именно хочешь изучать или делать в рамках этого курса в новом проекте?»

Используй существующий прогресс, программу и настройки. Даже незавершённая старая
анкета не повод повторять её при явном запросе конкретной работы в старом курсе.

new для известного ученика создаёт course_setup в прежнем preferences профиля.
course_intro возвращает по одному утверждённые вопросы 1, 2, 3, 8 и уточнения
предмета из onboarding-dialog.md. Сохраняй уже названные ответы до показа следующего.
Затем course_preferences спрашивает дословно:

«Оставим твои прежние настройки обучения или хочешь их изменить для нового курса?»

1. Оставить прежние.
2. Изменить настройки.

```text
PRIVATE_PYTHON PLUGIN_ROOT/scripts/course.py settings --course COURSE --course-settings keep
PRIVATE_PYTHON PLUGIN_ROOT/scripts/course.py settings --course COURSE --course-settings change --setting-question check_frequency
```

Без --setting-question change выбирает все вопросы 4–7; повторяй флаг для нужного
подмножества. Используй исходные формулировки и варианты. Ответы сохраняй через
--onboarding-file/--onboarding-skip, effective values — совместимыми --set.
В новом курсе profile-изменения локальны, не публикуются в общий профиль. Для
обычного старого курса локальные настройки меняй через --scope course. Только
явная просьба изменить общие настройки разрешает --scope learner.

none сохраняет отключённую привязку. При without_course не вызывай учебные init,
settings, diagnostic, запись попыток/checkpoint или изменение Roadmap. Помогай
обычным диалогом. Поменять выбор можно новым явным --choice с актуальной ревизией.

## Реальные ограничения идентификаторов Codex

--chat должен содержать реальный ID текущего чата. В проверенном окружении
доступен CODEX_THREAD_ID, скрипт использует его при отсутствии --chat. Это наблюдение
хоста, а не универсальная гарантия для всех версий Codex. Если ID отсутствует,
needs_chat_id=true; не выдумывай UUID, название папки или общий session вместо ID.
Чатовый выбор с new/existing/none без реального ID не записывается. Для самой
первой анкеты без ID возможно только прежнее подключение уровня проекта/дома;
это не обещание распознавать следующие чаты. Старые project-only подключения
не определяют, тот же это чат или другой; выбор уточняется один раз и сохраняется
по реальному ID. Старые connection CLI, схемы и явные отключения сохраняются.

[App-server](https://learn.chatgpt.com/docs/app-server) предоставляет thread.id
клиенту интеграции после thread/start/resume. Это не означает наличие такого
API у каждого установленного навыка. [Документация плагинов](https://developers.openai.com/plugins/build/plugins)
описывает отдельные переменные PLUGIN_ROOT/PLUGIN_DATA и hooks; новые hooks,
app-server подключения и чтение всех чатов здесь не внедряются. Сохранение выбора
проверено программно, живой UI Codex этим не подтверждён.


Старая привязка уровня проекта не считается выбором неизвестного чата. Явный
--profile другого ученика не может молча открыть прежнюю привязку чата: требуется
новый согласованный выбор. Недоступный сохранённый курс возвращает
connection_unavailable, а не разрешение продолжать обучение. При конфликте записи
подключения после создания курса папка курса сохраняется; не удаляй её автоматически,
так как на неё уже мог сослаться другой процесс. Прежде чем создавать ещё один
курс после ошибки, проверь сохранённую папку и подключения.
