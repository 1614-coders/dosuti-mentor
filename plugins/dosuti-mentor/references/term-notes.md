# Уточнения терминов (0.3.5)

Не меняй transcript.json или tutor_packet.json ради правильного термина.
`term-note --course COURSE --lesson LESSON` показывает интерпретации; добавление —
`--note-file JSON`, удаление — `--remove ID`. Запись с тем же ID требует явного удаления.

Пример JSON:
```json
{
  "id": "mono",
  "start": 806.36,
  "end": 818.96,
  "asr_text": "лимоны",
  "term": "Mono",
  "basis": "attached_code",
  "notes": "В исходнике объявлен Mono; это интерпретация ASR, звук не подтверждён.",
  "frames": [],
  "code": {"sha256": "<content_sha256 снимка>", "file": "src/Example.java"}
}
```

basis=attached_code требует текущий проверенный снимок, существующий файл и буквальное
наличие term в UTF-8 тексте. Это не доказывает, что класс упоминали именно тогда:
проверь смысл по видео, не выводи совпадение времени из одного приложенного файла.
При замене снимка нужно заново сверить аннотацию.

basis=screen требует code=null и 1–50 frames вида {"time":15,"sha256":"..."} из
context внутри [start,end). Сам просмотри оригиналы и убедись, что термин виден:
проверка SHA256 доказывает сохранность кадра, не распознаёт надпись.
basis=hypothesis требует frames=[] и code=null; предположение не становится
подтверждённым термином только потому, что оно подходит по теории.

asr_text должен буквально присутствовать в пересекающемся ASR-сегменте. Это
привязка к сегменту, не к точным границам отдельных слов. Полный текст ASR сохранён.
Context возвращает только пересекающиеся term_notes со статусом интерпретации.
При stale/requires_review не используй прежнее уточнение как надёжное свидетельство.
verbatim_speech_confirmed всегда false: экран и исходники не подтверждают дословную
речь. Подтверждение звука, повторный ASR/автоматический словарь в этот выпуск не входят.

При объяснении можно естественно сказать «здесь речь, вероятно, о Mono — этот тип
виден в приложенном репозитории». Не приписывай преподавателю исправленную дословную
цитату. Сохраняй конкурирующие версии как неопределённость; программа не разрешает
смысловые конфликты автоматически. Курсор продолжения пока не зависит от term_notes:
при продолжении перечитай их через context. Правки аннотаций не имеют отдельного
журнала редакций. Проверка множества аннотаций может замедлить context.
