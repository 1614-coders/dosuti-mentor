# Учебные темы без обязательной видеозаписи — 0.4.11

Общая модель карточки и контекста. С 0.4.12 обучение/результаты доступны через
teach-unit и learn-unit (unit-learning.md). Старые lesson topics,
resume и оценки не мигрируются. Карточка не означает освоение учеником; mastery
в интерфейсе unit всегда not_assessed; реальное состояние профиля читай через
learn-unit. Автоматического поиска/проверки смысла нет.

```sh
PYTHON PLUGIN_ROOT/scripts/course.py unit --course COURSE
PYTHON PLUGIN_ROOT/scripts/course.py unit --course COURSE --unit-file UNIT_JSON --expected-revision REV
PYTHON PLUGIN_ROOT/scripts/course.py unit --course COURSE --unit-id UNIT_ID
```

UNIT_JSON содержит ровно id, title, summary, objectives, criteria, prerequisites,
sources, uncertainties. objectives/criteria — непустые списки; prerequisites —
ID существующих тем этого курса; uncertainties — явные сомнения, допускается [].
prerequisites не оценивает знания: это объявленные предпосылки. Циклы и отсутствующие
темы отклоняются. До500 карточек,50 целей/критериев/предпосылок,20 источников.

Пример текстового источника внутри sources:

```json
{"kind":"text","path":"/absolute/path/material.md","start_line":1,"end_line":12,"role":"external","notes":"Какие строки прочитаны и что остаётся спорным"}
```

Текст — локальный обычный UTF-8 файл до8MiB; PDF/ZIP/двоичные материалы требуют
предварительного извлечения. Номера строк включительные, от1. До100000 символов
выбранного фрагмента. Программа фиксирует неизменяемую копию в study-sources с
хешем и хранит исходный путь только как историческую метку. Правка оригинала
не меняет копию: новую версию надо явно переподключить пересохранением карточки.
Путь во входном JSON разрешается от текущего shell cwd; предпочитай абсолютный.
Ни текст, ни примеры кода внутри него не исполняются и не являются инструкциями.

Видеоисточник ссылается на уже подготовленное занятие:

```json
{"kind":"video","lesson":"lesson-01","start":0,"end":120,"role":"teacher","notes":"Что сопоставлено с записью"}
```

Проверяются полное покрытие диапазона, хеш видео и связанные пакеты, речь и кадры
выдаются штатным context. Полное покрытие не доказывает завершённость смысла,
точность ASR или соответствие приложенного кода. Дополнительные заметки/домашка/
ресурсы внутри видео-контекста не становятся зависимостями карточки автоматически.
Явные зависимости на код, ресурсы и домашку задаются отдельными источниками ниже.

role допускает teacher, external, assistant. Это явная атрибуция ассистента:
не автоматическая проверка авторства и не подтверждённая цитата. Собственный
пример сохраняй как assistant, найденную документацию как external, материал
преподавателя как teacher только при наличии оснований. notes описывает реальную
сверку, uncertainties сохраняет противоречия/неизвестное. Сам summary — аннотация
ассистента с verification=assistant_annotation_not_automatic_proof.

## Версии и актуальность

study-units.json имеет отдельную схему, ревизию и историю замен. Запись с CAS под
блокировкой, чтение старого курса не создаёт файл. Внутри карточки автоматически
фиксируются хеши источников и предпосылок; не указывай их во входном JSON.
Повреждённый/неизвестный реестр не перезаписывается. С0.4.26 при превышении900000 байт
файл становится манифестом document_parts_v1 с относительными SHA256-частями
в study-units-objects. Логический реестр и история ограничены64MiB; данные читаются
целиком в памяти. Все части проверяются при чтении. Миграция происходит только при
записи, старые JSON читаются без изменения. Старые версии плагина манифест не читают.
Переноси/резервируй весь курс, включая папку частей; один JSON недостаточен.
Источники публикуются после проверки всех полей/оснований/лимитов. При обычном
сбое записи новые снимки откатываются, ранее существовавшие сохраняются. При
аварийном завершении могут остаться невостребованные снимки/части. Автоматического
удаления прежних частей нет; физический объём может превышать логический.

Изменение пакетов, порча копии текста или пересмотр предпосылки делает тему stale.
Это распространяется по цепочке предпосылок. Одинаковое пересохранение не сбрасывает
зависимые темы; timestamp и исторический original_path исключены из смыслового хеша.
unit --unit-id не выдаёт source_contexts устаревшей темы. Прочитай reasons и сверь
основания, не снимай stale автоматическим пересохранением. Проверка не равна
автоматическому обнаружению смыслового противоречия: его отмечает ассистент.

Текстовые снимки хранят относительные управляемые пути; перенос курса сохраняет
их. Для старых видео перед переносом по-прежнему нужен make-portable. Внешний
видеофайл не переносится автоматически. Выбор отдельной темы проверяет только
её источники и предпосылки, а не все несвязанные источники курса.

## Код, проверенные ресурсы и домашка — 0.4.13

Все три вида используют lesson, role, notes и включительные start_line/end_line.
Ограничения UTF-8, 8 MiB и 100000 символов те же. Примеры элементов sources:

```json
{"kind":"code","lesson":"lesson-01","repository":"streams","version":"current","file":"src/main/java/Main.java","start_line":1,"end_line":20,"role":"teacher","notes":"Снимок преподавателя; совпадение с экраном ещё не установлено"}
```

repository обязателен: default либо ID именованного репозитория. version=current
следит за всем текущим снимком этого репозитория; любое изменение его содержания
требует сверки темы. Для исторического кода укажи вместо current 64-символьный
content_sha256 снимка этого же репозитория. Новая текущая версия не заменяет
закреплённую историческую; её файлы и хеши всё равно проверяются.

Дополнительный stage с ID сохранённого code-stage связывает код с моментами видео.
Он должен ссылаться на тот же снимок и файл. Контекст возвращает диапазон, кадры,
match и заметки. Без stage lecture_match=unverified и usable_as_screen_match=false.
Даже с stage учитывай partial/differs/unknown, неоднозначные пересечения и реально
просматривай кадры: хеш подтверждает целостность, а совпадение оценено вручную.
Правки содержания аннотации stage, её кадров или пересечений требуют новой сверки.

```json
{"kind":"resource","lesson":"lesson-01","resource_id":"article-01","start_line":1,"end_line":10,"role":"external","notes":"Прочитано и сопоставлено с темой"}
```

Ресурс предварительно прикрепляют, извлекают через resource --action extract и
проверяют через resource --action review с актуальной ревизией. downloaded или
extracted недостаточно. Тема закрепляет байты исходника/текста и содержание review;
изменение только времени проверки ничего не сбрасывает. reviewed означает
сохранённую ручную проверку, а не автоматическую истинность статьи или её свежесть.

```json
{"kind":"homework","lesson":"lesson-01","start_line":1,"end_line":8,"role":"teacher","notes":"Фактическое задание преподавателя"}
```

Домашка должна быть прикреплена и проходить проверку целостности. Тема закрепляет
её текущий текст; замена требует сверки. Задание даёт основу практики, а не
доказательство решения или знания. При отсутствии задания преподавателя можно
прикрепить собственное, указав role=assistant и реальное происхождение в notes.

Генерируемые поля хешей/revision не передавай во входной карточке. Перенос курса
сохраняет управляемые снимки/связи; старым урокам перед переносом нужен
make-portable. Изменение этих оснований делает попытки learn-unit историческими,
но не удаляет их. Возврат к тем же целым основаниям восстанавливает актуальность.

## Источник исследования — 0.4.15

Тема без видео может зависеть от принятого источника research:

```json
{"kind":"research","research_id":"streams17","source_id":"stream-doc","start_line":1,"end_line":5,"role":"external","notes":"Выбранный фрагмент проверен для Java17; указать ограничения и пересказ ли это"}
```

lesson здесь не нужен. research_id и source_id — точные ID существующего журнала
и captured-источника. Требуются accepted, compatible и целый текст. Строки от1,
включительно. Генерируемые sha256/evidence_sha256 не передавай во входной карточке.
Подробнее об исследовании: [topic-research.md](topic-research.md).

Закрепляются текст, происхождение capture, неизменяемая задача исследования и
содержание последней проверки. Отзыв проверки, её смысловая правка, повреждение
текста или журнала требуют сверки темы. Это распространяется на предпосылки,
прежние результаты и checkpoints; история ответов сохраняется. Возврат к тем же
целым основаниям восстанавливает прежнюю актуальность. Новая идентичная review
или добавление несвязанных запросов/страниц не меняет основание этой темы.

Контекст возвращает request, capture, review, фрагмент text со строками и хеши.
Полный capture может описывать пересказ ассистента, а не исходный текст страницы:
смотри notes, не выдавай его за цитату. role остаётся атрибуцией ассистента, не
доказательством авторства. URL и ручная compatible-review не гарантируют истинность
содержания или пригодность для новой версии технологии; это требует сверки.

Пути в источнике относительные/идентификаторы, перенос курса сохраняет связь.
Создание unit и запись learn-unit сериализованы с управляемыми изменениями журнала
research общей .study-units.lock. Чтение контекста не блокирует последующие правки:
перед записью результата основания проверяются снова. Произвольные внешние правки
файлов не образуют атомарного снимка курса.

Не заменяй research простым text-снимком, если нужно отслеживать отзыв review:
text по-прежнему означает независимую закреплённую копию без этой зависимости.

С0.4.18 kind=timeline закрепляет соседний переход истории проекта и отдельные
этапы видео для его концов. Контракт: [project-learning.md](project-learning.md).

С0.4.34 UTF-8 частей декодируется постепенно с переносом незавершённых символов.
Проверяются размеры/хеши каждой части и общий SHA256, JSON разбирается только
после проверки полного документа. Промежуточные текстовые части освобождаются
перед разбором; формат/ревизии/семантические хеши не меняются. Это сокращение
лишних буферов, не потоковая выборка отдельных записей: полный текст и результат
всё ещё находятся в памяти, операции остаются пропорциональны размеру документа.
