# Общий локальный профиль и отдельные проекты

Общие данные находятся в DATA_ROOT/learner-preferences/PROFILE/preferences.json;
это тот же подход preferences + атомарная запись + блокировка, без новой БД.
Идентификатор PROFILE выбирается из существующего подключения. Профили разных
людей или управляемых домов не объединяются и не ищутся по диску.

Общие: style, format, detail, checks, communication_language; ответы
learning_format, assistant_role, check_frequency, explanation_detail и факт
завершённого/пропущенного общего знакомства. Язык общения не является языком кода.
Проектные: outcome, subject, self_assessment, constraints, level, произвольный
onboarding_comment, intent, диагностика, материалы и прогресс. Свободный комментарий
не публикуется в общем профиле автоматически. Не считай настройки доказательством знаний.

Новый проект или чат не создаёт курс автоматически. Известному ученику сначала
предлагаются существующий курс, новый курс или работа без привязки. Выбор хранится
в существующих connections, с CAS и проверенным ID чата. Один курс можно
подключить в нескольких проектах; оценки и материалы остаются в исходном курсе.
Порядок и CLI — в [start-choices.md](start-choices.md).

При явном запуске выбранного старого профиля с complete/skipped его безопасные
общие поля можно сохранить в общем профиле; исходный файл не меняется. Чтение
settings этого не делает. Другие курсы/профили не сканируются. Для внешнего курса
используй learner_home из learning_start как --learner-home.

В самой первой анкете full используются исходные восемь вопросов. После выбора
нового курса известным учеником course_intro использует вопросы 1, 2, 3, 8;
course_preferences предлагает прежние или изменённые настройки; course_settings
использует выбранные вопросы 4–7. ready позволяет сразу работать. Прежний project
остаётся совместимым представлением старых неполных локальных настроек; он не
означает разрешение создавать новый курс автоматически.

Примеры для ассистента (пути и значения подставляй фактические):

```text
PRIVATE_PYTHON PLUGIN_ROOT/scripts/course.py settings --course COURSE --profile PROFILE --compact
PRIVATE_PYTHON PLUGIN_ROOT/scripts/course.py settings --course COURSE --profile PROFILE --scope learner --set communication_language=Русский --set detail=concise
PRIVATE_PYTHON PLUGIN_ROOT/scripts/course.py settings --course COURSE --profile PROFILE --scope learner --set checks=each_block --expected-revision REVISION
PRIVATE_PYTHON PLUGIN_ROOT/scripts/course.py settings --course COURSE --profile PROFILE --restart-onboarding
```

--expected-revision для learner относится к layers.learner.revision (в compact —
preference_revisions.learner), для profile/course — к соответствующему локальному
слою. При конфликте перечитай настройки и уточни только реальный конфликт выбора.
Обновления отдельных общих полей объединяются под блокировкой, файл записывается
атомарно. Проектные значения course имеют приоритет над общими. После подключения общего
слоя прежние копии общих values в локальном profile не переопределяют его;
исключение — явные локальные настройки нового курса с course_setup. level
остаётся локальным. Полные старые записи сохраняются для совместимости. --reset очищает
значения выбранного слоя, но не историю обучения. --restart-onboarding начинает
полный опрос только для текущего проекта, не удаляет оценки, материалы и историю
и не заставляет остальные проекты знакомиться повторно. В новом курсе изменения
настроек через profile не публикуются в общий слой; для глобального изменения
нужен явный --scope learner. Для старых курсов локальное изменение делай через
--scope course, сохраняя совместимость прежнего profile-режима.

Старый --profiles-dir остаётся явным выбором общего файла старого формата;
не включай его автоматически вместо нового общего слоя и не переписывай такой
файл ради миграции. Если он уже используется для нескольких предметов, объясни
существующее общее хранение ответов и согласуй отдельные профили/подключения.

Ошибки общего файла, ссылки и обнаруженные hard links не обходятся подменой пути
или перезаписью. Сохрани файл и объясни необходимость восстановления. Ничего не
отправляется в облако как отдельный сервис профилей; в модель попадает только
контекст текущего запроса. Для разных пользователей общего компьютера используй
разные учётные записи/управляемые дома или разные PROFILE с корректными правами.
Это локальная идентификация, а не система аутентификации.


При восстановлении общего профиля course_setup не используется как источник:
локальные настройки нового курса не должны стать общими. При импорте старого
профиля уже сохранённые общие значения/ответы имеют приоритет над импортируемыми.
Общие и местные preferences записываются отдельными атомарными заменами, не общей
транзакцией. При ошибке диска во время двух записей сохрани оба файла, перечитай
ревизии и согласуй повтор; не считай сообщение об ошибке подтверждением полного
сохранения. Журналы учебных результатов при таком изменении не переписываются.
