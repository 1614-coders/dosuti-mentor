# Части документа: диагностика 0.4.36

Из корня пакета:

```sh
python plugins/dosuti-mentor/scripts/document_report.py --document /absolute/course/path/state.json --kind EXPECTED_KIND
```

Указать конкретный документ и его kind из формата подсистемы курса. Команда
самостоятельная; в обычный status полный обход не добавлен. Никаких lock-файлов,
каталогов или изменений документа не создаётся. Обычный inline JSON и прежний
`document_parts_v1` читаются без миграции. Родительские символические ссылки,
ссылки вместо документа/каталога объектов и hardlink документа отклоняются.
На macOS путь /var может быть символической ссылкой: используй фактический /private/var.

Проверяются структура manifest, kind, размеры, SHA256 каждой текущей части и
потока частей в исходном порядке. До 64MiB текущих данных читаются ограниченными
буферами. `current_bytes_verified` относится к этим байтам; логический JSON и его
учебная схема не разбираются и не подтверждаются (`logical_json_verified=false`).
Для inline формата `current_bytes_verified=false`, сам JSON разбирается в пределах
900000байт, но его прикладная схема не проверяется.

`referenced_*` и `unreferenced_*` считают размеры обычных single-link файлов с
именем SHA256.part и размером 1..256KiB, каждый путь один раз. Неупомянутые
в текущем manifest файлы НЕ объявляются устаревшими: ими ещё может пользоваться
читатель предыдущей версии, в том числе старый плагин. Содержимое/хеши таких файлов
не проверяются. `reclaimable_bytes=null`, `deletion_supported=false` всегда.

Неизвестные файлы, подкаталоги, ссылки, hardlinks и неподходящие размеры исключаются
из объёмов и считаются как `unknown_entries`. Ошибка доступа к каталогу/текущим
данным завершает команду ошибкой; отдельная неизвестная запись не останавливает
обход. Лимит `--max-entries` по умолчанию4096, диапазон1..100000; при превышении
`scan_complete=false`, итоги частичные. В JSON не более100 неупомянутых имён;
`sample_truncated` отмечает неполный список среди просмотренных записей.

Manifest и метаданные каталога сравниваются до/после; обнаруженное изменение
даёт `observed_unchanged=false`. Это не атомарный снимок и не доказательство
отсутствия активных читателей/писателей. Содержимое файлов может меняться между
проверками; команда не защищает от враждебной подмены путей тем же пользователем.
`scan_complete` означает только завершённый обход, не разрешение удаления.

Перед будущим GC нужна согласованная защита читателей/писателей и решение для
старых версий без такой защиты. Этот этап реализует только измерение. Не превращай
его JSON в список для rm и не обещай освобождение показанного объёма на APFS.
Отчёт может раскрыть хеши/размеры локального состояния, пересылать его вручную
только после просмотра; автоматической отправки и сетевых запросов нет.
