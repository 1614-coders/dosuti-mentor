# DoSuti Mentor 0.4.71 — привязка содержательного review

Дата: 2026-10-21. Продолжение повторной приёмки локального исправления 0.4.70.
На GitHub по-прежнему опубликована 0.4.69; коммит и push не выполнялись.

## Подтверждённый обход

Положительный, полностью оформленный review для HashMap можно было перенести в
target synchronized/happens-before: исходная цитата и критерий оставались настоящими,
а competence target менялась. Правильный ответ про put завершал шаг по потокам.
Review был связан с версией материала, но не явно с компетенцией и ответами.

## Изменение

В существующем alignment_review теперь явно сохраняются competence и
diagnostic_event_revisions. Валидация требует совпадения с target: точная строка
компетенции и тот же набор диагностических ответов, без bool/дубликатов.
Перенос разбора между компетенциями/наборами ответов отклоняется до записи.
Новый review без привязки не записывается. Пустые ссылки допустимы без диагностики.

Существующие v6 без обоих полей продолжают читаться как unreviewed. Они не
завершают шаг, но не теряют историю, независимые ответы и освоенные критерии unit.
Чтение не переписывает журналы. Схема остаётся v6, новых хранилищ нет.

Инструкции ассистенту запрещают механически менять привязку старого review:
нужна повторная содержательная проверка и отдельное предложение с принятием.
Это предотвращение случайного переноса, а не доказательство истинности объяснения.
Если ассистент намеренно или ошибочно составит новый неверный разбор с совпадающими
полями, код по-прежнему не умеет опровергать его смысл автоматически.

## Проверки

- Непосредственный повтор обхода: Map review + target synchronized теперь получает
  ValueError о несовпадении компетенции/ответов; исходный intent-журнал не меняется.
- Ошибочные цитаты и чужие критерии отклоняются; принятый план и unit-ответы
  остаются неизменными после неудачного обновления.
- Добавлены два регрессионных метода: перенос review и чтение старого v6 без
  привязки с сохранением истории/результатов и отсутствием записей при чтении.
- Профильный набор: 137 тестов, все прошли.
- Полный набор: 1107 тестов — 1092 успешно, 15 пропущены, ошибок/падений нет.
  Пропуски относятся к существующим Windows/PowerShell-зависимым проверкам.
- Мутация только в памяти: отключение сравнения competence приводит к падению
  регрессии переноса review. Исходные файлы при мутации не менялись.
- Проверка Python AST, plugin.json и git diff --check прошла.
