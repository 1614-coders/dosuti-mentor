# Первый запуск на Windows — чеклист пользователя

Это ручная проверка обычного знакомства, без отдельного тестового режима плагина.
Используй новую папку для обучения, чтобы не затронуть свои рабочие курсы.

1. **Установка.** Пройди Windows-раздел README. В PowerShell, открытом именно
   в распакованном репозитории, `codex --version` показывает версию, команды
   marketplace/plugin завершаются успешно, затем Install-DoSuti.ps1 готовит среду.
   Запиши версию Windows, Codex и плагина; при ошибке сохрани полный текст ошибки.
2. **Чистый запуск.** Открой отдельную пустую папку как проект Codex, создай чат
   и отправь только `$start-learning`. Ожидается приветствие, объяснение возможностей,
   «Вопрос 1 из 8», варианты и возможность пропуска. Не должно быть просьбы
   самостоятельно выполнять внутренние команды или читать JSON.
3. **Сохранение.** Ответь на первый вопрос, второй пропусти, затем скажи «пауза».
   Создай другой чат этого же проекта и отправь `$start-learning`. Ожидается
   «Вопрос 3 из 8», без повторного полного приветствия. Попроси изменить ответ
   на первый вопрос: меняется только он, продолжение остаётся на третьем.
4. **Завершение.** Пройди оставшиеся вопросы. В каждом сообщении только один
   вопрос, номер правильный. После восьмого — предложение диагностики с выбором
   «Да / Без диагностики / Позже», а не дополнительный вопрос анкеты. Сначала
   выбери «Позже»: диагностических задач ещё нет. Затем явно согласись на проверку.
   Отдельно проверь отказ: «Не хочу диагностику, давай учиться» не блокирует обучение.
5. **Повторный запуск и отзыв.** В новом чате того же проекта `$start-learning`
   не начинает восемь вопросов заново. Сохрани отзыв в Markdown: на каком шаге
   остановился, ожидаемый и фактический результат, текст ошибки/скриншот, что было
   непонятно. Отдельно отметь, появились ли JSON, пути и служебные инструкции в диалоге.

Отказ после уже начатой диагностики может предложить паузу текущей проверки;
это не тот же сценарий, что отказ до её начала. Для проверки первоначального
отказа используй ещё один пустой учебный проект с отдельным новым курсом.
