# DoSuti Mentor 0.4.73 — чтение при повреждённом маршруте

Дата: 2026-10-21. Локальное исправление поверх непубликовавшихся 0.4.70–0.4.72.
Коммит и push не выполнялись. Проверялись только временные QA-курсы.

## Подтверждённый дефект

При повреждённом JSON или неподдерживаемой схеме learning-intent.json функция
intent.view возвращала valid=false без learning_progress. Остальные команды
обращались к отсутствующему полю: study-next, learn-unit, resume и status
заканчивались KeyError, хотя независимые unit-ответы оставались исправными.
Регрессионные тесты до исправления воспроизвели три ошибки чтения.

## Минимальное исправление

- intent.view в ошибочной ветке читает существующие независимые lesson/unit-данные
  через прежний learning_progress с недоступным plan. Итог: valid=false,
  route_state=unknown, stopped_at=null, без текущего/следующего шага маршрута.
- Подтверждённые результаты, история и действующие continuations видны; это
  неполная сводка, а не разрешение продолжать автоматически. Причины других
  ошибок добавляются к причине intent, не затираются.
- study-next отражает неполный статус как valid=false и не выдаёт учебную очередь.
  roadmap.status=incomplete. Здоровые сценарии не менялись.
- Никакого восстановления, переименования, удаления или замены повреждённого
  журнала не происходит. Существующая блокировка записи intent остаётся.

Изменения производственного кода ограничены learning_intent.py и
adaptive_learning.py. Нового хранилища и миграции нет.

## Проверки

- Два новых тестовых метода test_incomplete_intent.py: повреждённый JSON и будущая
  схема, чтение через все затронутые команды, сохранение освоенной unit и checkpoint,
  отсутствие автоматического выбора, неизменность файлов и запрет записи поверх
  повреждённого intent. После возврата исходного файла завершённый шаг снова виден.
- Профильный набор: 67 тестов успешно.
- Полный набор: 1111 тестов — 1096 успешно, 15 пропущены, падений/ошибок нет.
  Пропуски прежние, связаны с Windows/PowerShell.
- Мутация только в памяти: удаление сброса stopped_at даёт ожидаемое падение
  регрессии. Исходные файлы при мутации не изменялись.
- git diff --check прошёл.

Версия повышена до 0.4.73; обновлены CHANGELOG.md и references/learning-intent.md.

## Ограничения

Невозможно восстановить саму цель/маршрут из повреждённого файла без исправной
копии: вывод содержит явную ошибку, а не выдуманный план. Другие повреждения также
могут сделать часть сводки недоступной; они не исправляются молча.
Живой диалог Codex и нативные Windows/Linux этим исправлением не проверены.
