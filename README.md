# DoSuti Mentor

Локальный помощник в обучении для Codex. Он помогает пройти курс, разобрать
видеолекцию с кодом и домашкой, изучить новую тему и закрепить знания практикой.
Цели, настройки и прогресс сохраняются в выбранном локальном курсе.

## Установка на Windows

В чате Codex отправь:

```text
Установи DoSuti Mentor из https://github.com/1614-coders/dosuti-mentor
Подключи GitHub marketplace, установи плагин и локальные компоненты.
Перед системными действиями запроси разрешения. Проверь результат.
Обучение пока не начинай.
```

Codex должен подключить marketplace, установить плагин и подготовить локальную
среду. От тебя могут потребоваться разрешения на сеть и запуск установщика.
ZIP скачивать не обязательно. Приветствие и учебные вопросы при установке не запускаются.
После проверок ожидаемый ответ:

> DoSuti Mentor установлен. Чтобы начать обучение, введи $start-learning в нужном чате.

**Ограничение Codex:** новые навыки могут потребовать нового чата/сессии; в некоторых
версиях приложения — перезапуска. Если команда `codex` недоступна, приложение и CLI
нельзя считать одним и тем же. Нужно разрешить установку Codex CLI по
[официальной инструкции](https://developers.openai.com/codex/cli) или использовать
фактически доступный интерфейс управления плагинами. Репозиторий не может сам
предоставить Codex недостающие права, инструменты или доступ к marketplace.
Не копируй исполняемый файл Codex в папку проекта.

Подробный порядок для Codex и ручной резервный вариант —
[инструкция установки](plugins/dosuti-mentor/references/installation.md).
Она содержит GitHub-команды marketplace и запуск установщика из установленного
пакета. Пакет включает Windows-установщик; отдельная распаковка репозитория не нужна.
При корпоративном запрете скриптов может потребоваться администратор.

## Первый разговор

В нужном чате, где доступен установленный плагин, отправь:

```text
$start-learning
```

Папку хранения выбирать не нужно. На Windows по умолчанию используются
`%LOCALAPPDATA%\DoSutiMentor`, курс `courses/default` и профиль `default`.
Они создаются при первом начале обучения, а не при одной лишь установке.
Существующее подключение чата/проекта важнее умолчания; старые курсы не переносятся.
Новый чат или проект без своего подключения использует тот же стандартный курс.
Внутри текущего проекта курс и файл подключения автоматически не создаются.

Наставник представится и задаст восемь вопросов — по одному, с номером
«Вопрос N из 8» и вариантами ответа. Можно отвечать своими словами, сказать
«пропустить», «пауза» или попросить изменить прежний ответ. Ответы сохраняются
после каждого шага. Новый чат в том же подключённом проекте продолжает знакомство.
Приветствие и варианты фиксированы в [тексте знакомства](plugins/dosuti-mentor/references/onboarding-dialog.md).
Уточнение широкой области остаётся вопросом 2. Свободные ответы и дополнения
сохраняются вместе с выбранными вариантами; менять формат можно без новой анкеты.
После восьмого вопроса будет предложена необязательная диагностика на ориентировочно
10–20 вопросов. «Без диагностики» позволяет сразу перейти к обучению.

Можно сразу отправить ссылку на видео или локальный файл, ссылку на репозиторий,
домашнее задание и дополнительные материалы. Не нужно заранее скачивать видео.
Для такого прямого запроса знакомство не является обязательным. Помощник разделит этапы: сбор материалов,
подготовку лекции и само занятие.

Для проверки всех девяти этапов на другом компьютере: [Windows-чеклист полного цикла](WINDOWS-CHECKLIST.md).

Для видео подготовка проходит локально: «скачиваю → распознаю речь → разбираю
кадры → связываю с кодом → занятие готово». Прогресс показывается, только когда
его можно честно посчитать. Ссылки с авторизацией, DRM, эфиры и плейлисты могут
потребовать обычный локальный файл.

## Данные и очистка

Новый стандартный курс, материалы и прогресс лежат в `DATA_ROOT/courses/default`.
Явно подключённые старые курсы остаются в своих папках. DATA_ROOT по умолчанию находится в `%LOCALAPPDATA%\DoSutiMentor` на Windows,
`~/Library/Application Support/DoSutiMentor` на macOS и
`~/.local/share/DoSutiMentor` на Linux. Её состав и безопасная очистка описаны
в [STORAGE.md](STORAGE.md).
Установка плагина и его кеш управляются самим Codex и могут находиться вне DATA_ROOT.
Удаление DATA_ROOT не удаляет установленный плагин или историю чатов Codex.

## Ограничения

Распознавание речи выполняется локально, но объяснение требует сверки речи,
кода и кадров: автоматический результат не гарантирует точность каждого факта.
Codex использует лимиты аккаунта. Подробные ручные команды — в
[commands.md](plugins/dosuti-mentor/references/commands.md).

Поддерживаются Windows x64, macOS на Apple Silicon и Intel, Linux x64/ARM64.
Нативный OCR доступен только на macOS; на других системах кадры остаются частью
материала для разбора в чате. Реальные прогоны Windows и Linux ещё нужны перед
стабильным выпуском.
