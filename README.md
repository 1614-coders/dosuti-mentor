# DoSuti Mentor

Помощник в обучении для Codex: разбор видеолекций, связь с кодом и заданиями,
объяснение материала в диалоге, практика и сохранение прогресса.

**0.4.40 — версия для внешнего тестирования.** Обработка проверена на macOS arm64
с Python 3.12. Полный прогон на Windows ещё не выполнен: первый пилот должен
проверить установку, знакомство, лекцию и продолжение в другом чате.

## Изменения0.4.40

Подготовка Windows-пилота одним сценарием: Start-WindowsPilot.ps1 проверяет Python,
а pilot_setup.py устанавливает личный runtime/модель, записывает версии и ранние
ошибки, затем действительно обрабатывает короткий фрагмент на CPU. Готовая среда
может быть проверена без загрузок. Тестовый курс подключается к отдельному проекту:
новый чат внутри него находит прогон без ручного копирования пути. Обычные курсы
и чужие привязки не заменяются. [Инструкция](WINDOWS-PILOT.md).

## Изменения 0.4.39

Исправлены три замечания сквозной проверки компактного режима. Короткое окно
скрывает пересказ всей темы и поздние примеры; устное задание можно сохранить
с таймкодами и проверенной трактовкой для обычной проверки домашки. Память v2
указывает объём сверки ASR, кадров, кода, звука и говорящих; для v1 он неизвестен.
Прежние курсы и архивы читаются без перезаписи. Подробнее:
[устная домашка](plugins/dosuti-mentor/references/spoken-homework.md),
[компактный режим](plugins/dosuti-mentor/references/compact-lecture.md).

## Изменения 0.4.38

`$compact-lecture` сохраняет учебную память пройденной лекции для повторения без
видео: объяснения по темам, примеры/этапы кода и ссылки на сохранённые кадры.
После сверки и согласования плана можно удалить скачанное видео, извлечённое
аудио и проверенные рабочие дубликаты. Расшифровка, все опубликованные кадры,
код, задания и прогресс сохраняются. Локальный оригинал пользователя защищён.
Удаление явное, восстанавливается после прерывания; для новых кадров/ASR нужен
возврат оригинала. Автоматическая проверка не доказывает полноту объяснения.
Подробности: [compact-lecture.md](plugins/dosuti-mentor/references/compact-lecture.md).

## Изменения 0.4.37

При продолжении темы прежние редакции реестра проверяются по одной, без удержания
всех старых объектов и полного текста в памяти. Текущие темы, зависимости,
источники, попытки и точки продолжения проверяются как прежде. Формат курса прежний.
На двух синтетических реестрах3–9МБ пик выделений Python снизился на31–45%;
это не RSS, чтение в этом замере примерно на6% медленнее. Все байты читаются и
проверяются; это выборочное построение объектов, а не пропуск проверки истории.
Подробности: [registry-projection.md](plugins/dosuti-mentor/references/registry-projection.md).

## Изменения 0.4.36

Добавлен отчёт по частям одного документа: текущие ссылки, проверка хешей,
объём файлов вне текущей версии и ограниченный список таких файлов.
Команда ничего не удаляет: неупомянутые части могут ещё читаться старым процессом.
Формат хранения и прогресс не меняются. Это диагностика перед будущей очисткой.
Подробности: [document-report.md](plugins/dosuti-mentor/references/document-report.md).

## Изменения 0.4.35

Добавлены план и очистка проверенных устаревших сборок локального OCR-движка.
Текущая, занятая или изменённая сборка сохраняется; прерванное удаление можно
завершить новой версией. Учебные материалы/ответы и части истории не удаляются.
Команда работает на macOS, автоматическая очистка не включена.
Подробности: [native-cleanup.md](plugins/dosuti-mentor/references/native-cleanup.md).

## Изменения 0.4.34

Чтение крупных документов декодирует UTF-8 по частям и освобождает промежуточные
буферы до разбора JSON. В локальном замере на трёх синтетических документах6–10МБ
пик Python-выделений снизился на26–41%; это не RSS всего приложения и не гарантия
для любого курса. Все части/общий хеш проверяются, формат хранения прежний.
Полный текст и итоговый документ всё ещё восстанавливаются в памяти.

## Изменения 0.4.33

Одновременные OCR-запросы одного кадра и области распознаются один раз, а ожидающие
чаты получают проверенный кэш. Источник и движок сверяются после ожидания; ошибочный
ответ движка не публикуется. Форматы прежних курсов и расшифровок сохранены.
Это не повышение точности распознавания и не добавление OCR на Windows.

## Установка в Codex

Добавить источник плагинов из этого репозитория:

```sh
codex plugin marketplace add https://github.com/1614-coders/dosuti-mentor.git
codex plugin add dosuti-mentor@dosuti-mentor-local
```

Если CLI недоступна в PATH, использовать каталог плагинов поддерживаемого клиента
Codex для добавления источника GitHub. Возможности интерфейса зависят от клиента.
После установки открыть новый чат. Установка плагина и установка локального
обработчика — отдельные шаги; Codex может провести по ним.

## Начало

- `$start-learning` — обсудить цель, уровень, подачу материала и ближайший шаг.
- `$prepare-lecture` — добавить видео, связанный код, домашку и дополнительные материалы.
- `$teach-lecture` — изучать подготовленную лекцию с кадрами и примерами кода.
- `$research-topic` — найти и проверить источники для новой учебной темы.
- `$teach-unit` / `$teach-project` — изучать тему или развитие проекта.
- `$review-homework` / `$review-learning` — практика, обратная связь и повторение.
- `$compact-lecture` — сохранить материал для повторения и согласовать очистку медиа.
- `$plan-career` — обсудить путь к профессии и требования по датированной выборке.

Навыки могут показываться с префиксом `dosuti-mentor:`. Курс связывается с чатом
или проектом по явному выбору. Прогресс одного профиля используется между чатами,
точки продолжения различаются по session. Учебные данные хранятся вне плагина.

## Тестовый прогон для друга

Открыть отдельную рабочую папку и новый чат, вызвать `$test-learning`.
Прогон создаёт отдельный курс/профиль и журнал этапов. После знакомства и короткого
медиа-прогона можно обработать свою лекцию, получить объяснение, решить задачу,
проверить продолжение в новом чате и экспортировать `TEST_REPORT.md`.
Оценки не придумываются; пропущенное и непроверенное не считаются успехом.
Отчёт содержит технические наблюдения и отдельно отзыв тестировщика.

## Локальная обработка

Требуется Python 3.11+ (проверен 3.12). Пример для macOS/Linux из корня репозитория:

```sh
python3 plugins/dosuti-mentor/scripts/setup_local.py --runtime /absolute/path/data/runtime
```

На Windows использовать Python 3.12 и `runtime/venv/Scripts/python.exe`;
PowerShell-пример приведён в Windows-инструкции. Активация venv не требуется.
Зависимости и модель речи при первой установке скачиваются из интернета.
Начинать с CPU и короткого видео; возможности оборудования влияют на время.
Для приветствия и обсуждения цели модель распознавания речи не нужна.

Речь и кадры обрабатываются локально без отдельного платного API. Сам диалог
Codex использует доступ и лимиты аккаунта; вся система не является офлайн-LLM.
Apple Vision OCR работает только на macOS со Swift. На Windows он недоступен:
можно разбирать исходные кадры в чате, если клиент поддерживает просмотр изображений.
OCR и распознанная речь могут ошибаться. Совпадение кода с экраном требует сверки;
финальная версия репозитория не подменяет промежуточный код преподавателя.

Полное видео, его код и домашка не обязательны одновременно. Частичный или
повреждённый материал отмечается явно. Доступность внешних ссылок зависит от сайта;
при проблемах можно предоставить обычный локальный видеофайл.

## Данные и обновления

Хранить курсы, runtime и модели вне папки плагина и установочного кэша.
При переносе сохранять весь курс, включая историю и части документов.
Внешние видео/runtime сами не переносятся. Старый `.lecture-tutor.json`
поддерживается; новые подключения используют `.dosuti-mentor.json`.
Прежняя установка Lecture Tutor удаляется отдельно, чтобы навыки не дублировались.

Отчёт пилота экспортируется локально, автоматической отправки нет. Перед ручной
передачей проверить заметки на личные данные. Удаление плагина не удаляет курсы;
сначала сохранить нужный отчёт вне тестовой папки, затем удалить только тестовые
данные по желанию. Общие Python/Git и данные других проектов не удалять.

## Проверки и ограничения

Последняя локальная регрессия: **826 тестов** на macOS. Проверены старые подключения
и журналы, CLI исходной/установленной версии. Это не подтверждает Windows-запуск
или качество каждого объяснения. Чужой компьютер и отзыв ученика — следующий этап.

```sh
python3 -m unittest discover -s plugins/dosuti-mentor/tests
```

Полный набор требует runtime-зависимости и разрешённый localhost для HTTP-fixture.
Это тесты разработки, не обязательный первый шаг ученика.
