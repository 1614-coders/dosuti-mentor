# DoSuti Mentor

Локальный помощник в обучении для Codex. Он помогает пройти курс, разобрать
видеолекцию с кодом и домашкой, изучить новую тему и закрепить знания практикой.
Цели, настройки и прогресс сохраняются в выбранном локальном курсе.

## Установка на Windows, macOS и Linux

1. Скачай репозиторий через **Code → Download ZIP** и распакуй архив в обычную
   папку, например `Документы\\DoSuti-Mentor`.
2. Открой терминал в этой папке: PowerShell на Windows, Terminal на macOS или
   любой shell на Linux. На Windows: открой распакованную папку в Проводнике,
   введи `powershell` в её адресной строке и нажми Enter.
3. Выполни по одной команде:

```powershell
codex --version
codex plugin marketplace add .
codex plugin add dosuti-mentor@dosuti-mentor-local
```

Первая команда должна вывести версию Codex. Если она пишет, что `codex` не
найден, сначала установи Codex CLI и открой новое окно терминала. После успешной
установки перезапусти приложение Codex, если навыки не появились.
Приложение Codex и доступность команды `codex` в PowerShell — разные вещи.
Проверь установку CLI по [официальной инструкции](https://developers.openai.com/codex/cli).
Не перемещай исполняемый файл Codex в папку проекта. Точка в `marketplace add .`
обозначает текущую папку с распакованным репозиторием, а не папку установки Codex.

Затем подготовь локальную среду. Она использует только выбранную папку данных:
зависимости, модель и временные файлы не попадают в системный Python, PATH или
папку установленного плагина.

**Windows:** в том же PowerShell выполни:

```powershell
.\Install-DoSuti.ps1
```

Если Windows блокирует скачанный скрипт, для этого запуска используй отдельный
процесс PowerShell; глобальные настройки системы менять не требуется:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-DoSuti.ps1
```

Скрипт ищет подходящий CPython 3.11/3.12. Если его нет, он скачивает проверенную
приватную копию в `%LOCALAPPDATA%\DoSutiMentor\runtime\python`.
Для своей папки данных у Windows-установщика есть параметр `-HomePath`:

```powershell
.\Install-DoSuti.ps1 -HomePath "D:\DoSuti Data"
```

Дополнительные параметры: `-Python "ПУТЬ\python.exe"` для своего интерпретатора
и `-Offline` для запрета скачивания самого Python. Установка библиотек всё равно
может потребовать интернет. Параметров `--home` и `--check` у этого PowerShell-скрипта нет.

**macOS и Linux:** в Terminal из папки репозитория выполни:

```sh
chmod +x install-dosuti.sh
./install-dosuti.sh
```

Нужен установленный `python3` версии 3.11 или 3.12. Скрипт не ставит системные
пакеты: если такого Python нет, он завершится с понятной ошибкой.

Для macOS/Linux другая папка данных: `./install-dosuti.sh --home "ПУТЬ"`.
Проверка совместимости без установки на macOS/Linux: `./install-dosuti.sh --check`.

## Первый разговор

Для первого запуска создай отдельную пустую папку для своего обучения и открой
её как проект в Codex. Не используй для курса папку установленного плагина или
распакованного репозитория. В новом чате достаточно одного сообщения:

```text
$start-learning
```

Наставник представится и задаст восемь вопросов — по одному, с номером
«Вопрос N из 8» и вариантами ответа. Можно отвечать своими словами, сказать
«пропустить», «пауза» или попросить изменить прежний ответ. Ответы сохраняются
после каждого шага. Новый чат в том же подключённом проекте продолжает знакомство.
После восьмого вопроса будет предложена необязательная диагностика на ориентировочно
10–20 вопросов. «Без диагностики» позволяет сразу перейти к обучению.

Можно сразу отправить ссылку на видео или локальный файл, ссылку на репозиторий,
домашнее задание и дополнительные материалы. Не нужно заранее скачивать видео.
Для такого прямого запроса знакомство не является обязательным. Помощник разделит этапы: сбор материалов,
подготовку лекции и само занятие.

Для проверки всех девяти этапов на другом компьютере: [Windows-чеклист полного цикла](WINDOWS-CHECKLIST.md).

Для видео подготовка проходит локально: «скачиваю → распознаю речь → разбираю
кадры → связываю с кодом → занятие готово». Прогресс показывается, только когда
его можно честно посчитать. Ссылки с авторизацией, DRM, эфиры и плейлисты могут
потребовать обычный локальный файл.

## Данные и очистка

Курс, материалы и прогресс лежат в папке, которую выбирает пользователь. Среда
по умолчанию находится в `%LOCALAPPDATA%\DoSutiMentor` на Windows,
`~/Library/Application Support/DoSutiMentor` на macOS и
`~/.local/share/DoSutiMentor` на Linux. Её состав и безопасная очистка описаны
в [STORAGE.md](STORAGE.md).
Удаление этой папки не удаляет установленный плагин или историю чатов Codex.

## Ограничения

Распознавание речи выполняется локально, но объяснение требует сверки речи,
кода и кадров: автоматический результат не гарантирует точность каждого факта.
Codex использует лимиты аккаунта. Подробные ручные команды — в
[commands.md](plugins/dosuti-mentor/references/commands.md).

Поддерживаются Windows x64, macOS на Apple Silicon и Intel, Linux x64/ARM64.
Нативный OCR доступен только на macOS; на других системах кадры остаются частью
материала для разбора в чате. Реальные прогоны Windows и Linux ещё нужны перед
стабильным выпуском.
