# DoSuti Mentor

Помощник в обучении для Codex: разбирает видеолекции, связывает их с кодом и
домашкой, помогает объяснять материал, практиковаться и сохранять прогресс.

**Версия 0.4.45 — для внешнего тестирования.** Ниже — один маршрут первого запуска
на Windows x64. Работа проверена на Mac; настоящий Windows-прогон ещё предстоит.

## Первый запуск на Windows

### 1. Подготовь компьютер и скачай файлы

Нужны приложение Codex с доступом к локальным папкам и плагинам, Python 3.12
с Windows launcher `py`, интернет для первой загрузки и локальное видео с речью.
Для команд подключения ниже также нужен Codex CLI — команда `codex` в PowerShell.

На странице этого репозитория нажми зелёную **Code → Download ZIP**. В Проводнике
нажми на архив правой кнопкой → **Извлечь всё**. Открой распакованную папку:
внутри должны быть `README.md`, `Start-WindowsPilot.ps1` и папка `plugins`.

В адресной строке этой папки набери `powershell` и нажми Enter. Откроется окно
команд в нужной папке. Проверь:

```powershell
py -3.12 --version
codex --version
```

Если одна из команд не найдена, сначала выполни подсказку из
[раздела об ошибках](WINDOWS-PILOT.md), затем вернись сюда.

### 2. Подключи плагин к Codex

В том же PowerShell выполни по очереди:

```powershell
codex plugin marketplace add https://github.com/1614-coders/dosuti-mentor.git
codex plugin add dosuti-mentor@dosuti-mentor-local
```

Первая команда добавляет источник плагинов, вторая устанавливает DoSuti Mentor.
Дождись успешного завершения обеих. Это подключение плагина; обработчик видео
подготовится на следующем шаге. Способ подключения источников описан в
[официальной документации OpenAI](https://developers.openai.com/plugins/build/plugins).

### 3. Подготовь обработку видео

В следующей команде **замени `C:\Videos\lecture.mp4` на полный путь к своему видео**.
Выбери запись, где в первые 30 секунд слышна речь.

```powershell
.\Start-WindowsPilot.ps1 -Video 'C:\Videos\lecture.mp4'
```

Сценарий установит зависимости в отдельную папку, скачает модель и действительно
обработает короткий фрагмент на CPU. Первый запуск может занять время из-за
загрузок; логи обновляются во время работы. Видеокарта NVIDIA не требуется.

Дождись `status: passed` в итоговом выводе. Там будут пути `project`, `pilot`,
`setup_report` и `report`. Если появилась ошибка, переходи к
[подсказкам](WINDOWS-PILOT.md); обычный курс вместо тестового создавать не нужно.

### 4. Открой тестовый проект и начни проверку

В приложении Codex открой **именно папку из поля `project`** как проект.
По умолчанию это `%LOCALAPPDATA%\DoSutiMentorPilot\project`.
Создай внутри него новый чат и отправь:

```text
$test-learning
Проведи тестовый прогон на Windows. Используй тестовый курс, уже подключённый
к этому проекту. Проверь знакомство, цель и настройки, разбери мою лекцию
с кодом и домашкой, проведи небольшой урок и сохраняй результаты в отчёт.
```

Если навык показан с префиксом, выбери `$dosuti-mentor:test-learning` из доступных
навыков. Codex задаст вопросы и попросит материалы. Отвечай как обычный ученик;
пропущенные этапы тоже можно записать в отчёт.

### 5. Проверь продолжение в другом чате

Открой **новый чат в том же тестовом проекте** и напиши:

> Продолжи тест DoSuti Mentor. Восстанови сохранённую цель, настройки и место,
> где мы остановились. Не создавай новый курс.

Привязка проекта позволяет найти тест без копирования пути. Проверь, что Codex
действительно восстановил нужные данные. Вне этого проекта нужен явный выбор курса.

### 6. Сохрани отчёт и передай его

В чате попроси:

> Экспортируй итоговый тестовый отчёт, запиши мой отзыв отдельно от своих
> наблюдений. Сохрани единый TEST_REPORT.md вне тестовой папки, включая время,
> вопросы, ответы, оценки и ошибки установки.

По умолчанию файлы находятся здесь:

```text
%LOCALAPPDATA%\DoSutiMentorPilot\run\TEST_REPORT.md
%LOCALAPPDATA%\DoSutiMentorPilot\SETUP_REPORT.md
```

TEST_REPORT.md объединяет этапы установки и обучения. Если run ещё не появился,
доступен отдельный SETUP_REPORT.md. Сохрани итоговый файл в другую папку,
проверь личные данные и передай тому,
кто проводит тестирование. Ничего автоматически не отправляется. Если установка
не дошла до курса, передай доступный отчёт об ошибке или заполни
[ручной шаблон](TEST_REPORT_TEMPLATE.md).

**Не удаляй тестовую папку до копирования отчётов.** Как удалить плагин и тестовые
данные отдельно — в [инструкции Windows](WINDOWS-PILOT.md#после-теста).

## Возможности

- `$start-learning` — цель, уровень, предпочтения и учебный маршрут.
- `$prepare-lecture` / `$teach-lecture` — подготовка записи и обучение по ней.
- `$research-topic` / `$teach-unit` — материалы и урок по отдельной теме.
- `$teach-project` — обучение через развитие проекта между занятиями.
- `$review-homework` / `$review-learning` — практика, проверка и повторение.
- `$compact-lecture` — сохранение материала и согласованная очистка медиа.
- `$plan-career` — обсуждение пути к профессии.

## Хранение, стоимость и ограничения

Распознавание речи и подготовка кадров выполняются локально без отдельного платного
API. Сам Codex использует доступ и лимиты аккаунта. Первые загрузки требуют сети;
курсы, runtime и модели хранятся отдельно от установки плагина.

Речь и OCR могут ошибаться; код нужно сверять с конкретными моментами видео.
Apple Vision OCR доступен только на macOS; на Windows можно разбирать сохранённые
кадры в чате, если клиент поддерживает просмотр изображений.

Прогресс одного профиля общий для его чатов, точки продолжения — отдельные.
Удаление плагина само по себе не удаляет курсы, runtime и модели.

## Для разработки и других платформ

Локально прошли **919 тестов** на macOS. Проверены установка в новый venv,
скачивание модели, короткая CPU-обработка и повтор без сети. Это не подтверждение
Windows-запуска или точности каждого объяснения. Подробности: [TEST_REPORT.md](TEST_REPORT.md).

Команды для macOS/Linux, работа с существующим runtime и контракты хранения:
[commands.md](plugins/dosuti-mentor/references/commands.md).

```sh
python3 -m unittest discover -s plugins/dosuti-mentor/tests
```

Тестам разработки нужны зависимости runtime и разрешённый localhost.
Первому пользователю запускать весь набор не требуется. Лицензия: [MIT](LICENSE).


### Остатки после сбоя

Если обработка была принудительно закрыта, `storage-report` покажет оставшиеся
временные журналы. `cleanup-progress --course COURSE --profile PROFILE` проверит
кандидатов под блокировками записи; добавь `--apply`, чтобы удалить проверенные
остатки. Учебный журнал и используемые сегменты сохраняются.
Подробнее: [диагностика и очистка](plugins/dosuti-mentor/references/storage-report.md).
