# DoSuti Mentor

Помощник в Codex, который объясняет темы, предлагает практику и помогает
продолжать обучение с сохранённого места.

## Что умеет

- Помогает выбрать цель и составить учебный план.
- Разбирает темы, код, домашние задания и учебные материалы.
- Сохраняет курсы, профили и прогресс на вашем компьютере.

## Как установить

Нужны Codex и интернет. Откройте папку для занятий и отправьте в чат этот запрос:

```text
Установи и настрой DoSuti Mentor из 1614-coders/dosuti-mentor,
только из стабильной ветки main, без подмены локальной копией.

Сначала проверь существующее подключение. Если источник другой,
сообщи об этом и дождись моего согласия на замену.
Не удаляй мои курсы, прогресс и настройки.

Проверь доступные команды Codex, затем используй:
codex plugin marketplace add 1614-coders/dosuti-mentor --ref main
codex plugin add dosuti-mentor@dosuti-mentor-local

Если нужный источник и плагин уже подключены, не добавляй их повторно.
Проверь источник main, фактическую версию и локальные компоненты
через setup-dosuti. Если проверка не удалась, объясни причину.
Обучение пока не начинай.
```

Подтвердите необходимые действия, когда Codex запросит разрешение.
Доступ к аккаунту владельца и права записи в GitHub не нужны.
Если установить не получилось — [подробная инструкция](plugins/dosuti-mentor/references/installation.md#подключение-marketplace).

## Как начать

После успешной настройки откройте новый чат и отправьте:

```text
$start-learning
```

Наставник поможет выбрать курс или начнёт знакомство с восьми вопросов по одному.
Можно сразу написать свою цель: «Хочу разобраться в Java Map».

## Как обновить

Остановите обработку материалов и сохраните [копию учебных данных](plugins/dosuti-mentor/references/installation.md#ручная-копия-учебных-данных-при-остановленных-процессах).
Попросите Codex: «Обнови DoSuti Mentor из main репозитория
1614-coders/dosuti-mentor. Сохрани мои курсы, прогресс и настройки.
Проверь источник, фактически установленную версию и готовность к работе».
После проверки откройте новый чат.
