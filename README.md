# DoSuti Mentor

Помощник в обучении для Codex: помогает проходить курс, разбирать лекции с кодом
и домашкой, изучать темы и закреплять знания на практике. Цель, настройки и
результаты сохраняются в локальном курсе.

**Тестовая версия 0.4.57.**
На странице репозитория нажми **Code → Download ZIP** или используй переданный
архив `dosuti-mentor.zip` той же версии.
Инструкция ниже — для Windows x64. Настоящая проверка на Windows ещё предстоит.

## Первый запуск на Windows

### 1. Распакуй архив

Нужны приложение Codex с поддержкой локальных папок и плагинов, интернет
и ссылка на лекцию либо видеофайл. Python вручную ставить не нужно.

Нажми на архив правой кнопкой → **Извлечь всё**. Открой распакованную папку,
в которой лежат **README.md**, **Start-WindowsPilot.ps1**, **Windows-Runtime.ps1**
и **plugins**. Дальнейшие команды запускаются именно из неё.
Не распаковывай её внутрь папки данных `%LOCALAPPDATA%\DoSutiMentorPilot`.

### 2. Установи плагин

В адресной строке открытой папки в Проводнике напиши `powershell` и нажми Enter.
В появившееся окно вставляй команды по одной, каждый раз нажимая Enter:

```powershell
codex --version
codex plugin marketplace add .
codex plugin add dosuti-mentor@dosuti-mentor-local
```

После первой команды должен появиться номер версии, остальные должны завершиться
без ошибки. Если `codex` не найден, следуй [подсказке](WINDOWS-PILOT.md#команда-codex-не-найдена).
Если источник уже подключён из другой папки — [как переключить источник](WINDOWS-PILOT.md#источник-плагина-уже-подключён).
После установки заново открой приложение Codex, если новые навыки не появились.

### 3. Начни в чате и отправь ссылку

В приложении Codex открой **распакованную папку из шага 1 как проект**.
Создай в ней чат и отправь:

```text
$test-learning
Начни тест DoSuti Mentor здесь и подключи тестовый курс к этой папке.
Выясни мою цель и удобный формат. Я пришлю ссылку на лекцию или файл,
а ты сам подготовь среду, скачай видео и помоги его разобрать.
Сохраняй этапы, время и ошибки в тестовый отчёт.
```

Если навык показан с префиксом, выбери `$dosuti-mentor:test-learning`.
Расскажи о цели, опыте и удобном формате; отправь **ссылку или файл**,
код/репозиторий, домашку и дополнительные материалы, если они есть.
Знакомство можно пропустить. Предварительно скачивать видео или вручную запускать
команды его обработки не требуется.

Codex запустит установщик из этой папки: проверит Python, подготовит зависимости
и модель `small`, скачает видео и обработает короткий фрагмент для проверки среды.
Первый запуск может занять время из-за загрузок. Затем он подготовит нужный материал,
обозначит готовый диапазон и начнёт урок. Проверка первых секунд не означает
готовность всей лекции. Если там тишина, можно выбрать другой момент без нового
скачивания файла.

Во время обработки Codex может показать текущий этап и время попытки. После
сбоя повторный запуск использует проверенные готовые этапы; незавершённое
распознавание речи начнётся заново. Завершение обработки ещё требует сверки
источников и кода перед уроком.

Для этого Codex должен иметь доступ к исполнению команд и выбранной папке.
Если запуск запрещён политикой PowerShell или инструмент недоступен, чат объяснит
причину; [запасной ручной запуск](WINDOWS-PILOT.md#запасной-запуск-по-ссылке).
Ссылки с авторизацией, DRM или неподдерживаемой площадки могут потребовать локальный
файл — обход ограничений не предусмотрен. Материалы можно добавить позже.

### 4. Проверь продолжение и сохрани отчёт

В **новом чате того же проекта** напиши:

> Продолжи тест DoSuti Mentor с сохранённого места. Восстанови цель и настройки,
> не создавай новый курс.

После проверки напиши свой отзыв и попроси:

> Добавь мой отзыв в итоговый TEST_REPORT.md отдельно от своих наблюдений.
> Включи время этапов и ошибки. Экспортируй файл за пределы тестовой папки
> и покажи, где он сохранён. Незавершённые проверки отметь как непройденные.

В отчёт также попадут замеры ОЗУ и CPU технических операций на Windows,
свободного места и размера папки данных. Короткие пики могут быть пропущены;
паузы между командами и отдельная работа Codex/браузера не измеряются.

Передай этот файл организатору теста. Ничего автоматически не отправляется.
Если установка оборвалась раньше, передай `SETUP_REPORT.md` или текст ошибки —
[где найти отчёты](WINDOWS-PILOT.md#где-отчёт-если-что-то-сломалось).
**Сначала сохрани отчёт, потом удаляй тестовые данные.**
Для этого есть `Complete-WindowsPilot.ps1`: он сначала готовит внешний план
и может работать даже с единственным приватным Python. Если установка
оборвалась до создания курса, та же команда сохранит доступные журналы
и подготовит план удаления её остатков.
[Удаление после теста](WINDOWS-PILOT.md#после-теста).

## Где хранятся файлы

Данные нового теста — курс, зависимости, модели, кеши и отчёты — находятся в
`%LOCALAPPDATA%\DoSutiMentorPilot`. Вставь путь в Проводник, чтобы открыть папку.
Исходный видеофайл, существующий общий Python и установленный плагин Codex
хранятся отдельно. Для другого места и подробностей очистки см. [STORAGE.md](STORAGE.md).

## Возможности и ограничения

Можно разбирать свои лекции, подбирать материалы по теме доступными средствами
поиска Codex, учиться через проект, проверять домашку и повторять пройденное.
Для обычного обучения после теста начни с `$start-learning` в отдельном обычном
курсе: тестовые оценки туда автоматически не переносятся.

Распознавание речи локальное, без отдельного платного API; сам Codex использует
доступ и лимиты аккаунта. Речь и экранный код требуют сверки, подготовка файлов
не гарантирует точность каждого объяснения. Apple Vision OCR работает только на
macOS; на Windows кадры можно просматривать в чате при поддержке клиента.
Прогресс общий для чатов одного профиля, личные настройки не меняют плагин у друзей.
