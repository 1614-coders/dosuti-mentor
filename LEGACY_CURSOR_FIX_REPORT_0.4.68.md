# DoSuti Mentor 0.4.68 — независимое чтение legacy-курсора

Дата: 2026-10-19. Проверенный актуальный main:
`e8c7722ec2d498da9aa63323245a2f41c93146b5` (0.4.67).
Локальная ветка: `fix/legacy-cursor-0468`. Коммит и push не выполнялись.

## Воспроизведение

Новые регрессионные тесты на исходной версии воспроизвели четыре падения:
WAL без unit скрывал курсор; WAL с unit скрывал курсор и оставлял только unit;
WAL с одним unit позволял автоматический stopped_at при неполных данных;
повреждённый cursor.json не делал результат неполным.
Воспроизведение использует настоящую SQLite в rollback/WAL, без подмены читателей.

## Исправление

Изменение поведения ограничено learning_progress в learning_intent.py:

- Чтение cursor.json вынесено из SQLite-try в независимый try.
- WAL-ошибка по-прежнему сохраняет valid=false и конкретную причину SQLite,
  но больше не скрывает независимый курсор.
- При повреждённом курсоре добавляется ошибка legacy cursor. Прочитанные
  lesson/unit-результаты сохраняются; причины ошибок дополняются, а не затираются.
- Несколько действующих продолжений дают continuation_choice_required=true
  и stopped_at=null. При любом valid=false stopped_at также остаётся null,
  даже если из неполных данных видна лишь одна действующая точка.
- Отсутствие курсора не является ошибкой. При полном прогрессе с единственным
  действующим курсором сохраняется прежний выбор stopped_at.

Автоматический WAL-checkpoint, миграция, изменения SQLite, новые хранилища и
адаптация Roadmap не добавлялись. CAS и механизмы записи не изменены.

- Целевые проверки: 100 тестов, все прошли.
- Полный набор: **1074 теста, 1059 успешно, 15 пропущены, ошибок/падений нет**.

  `../../../../venv/bin/python -m unittest discover -s . -p 'test_*.py'`.
  Локальные HTTP-fixtures выполнялись с разрешённым запуском вне sandbox.

## Ограничения

- Чтение WAL-прогресса по-прежнему блокируется существующим read-only механизмом.
  Его ошибка теперь не мешает чтению независимого cursor.json.
- Повреждённый курсор автоматически не исправляется и не удаляется.
- 15 пропусков полного набора относятся к PowerShell/Windows-зависимым проверкам.
  Нативные Windows/Linux и реальный диалог Codex в этом изменении не проверялись.
- Единый атомарный снимок нескольких независимых хранилищ не добавлен:
  при параллельной записи из другого чата сводку следует перечитать.
